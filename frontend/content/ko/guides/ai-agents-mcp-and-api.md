# AI 에이전트, MCP, API란: 채용에서 활용하는 방법

대부분의 사람은 AI를 채팅 창으로 처음 접했습니다. 질문하면 답이 돌아옵니다. AI 에이전트는 여기서 한 걸음 더 나아갑니다. 사용하는 도구 안에서 정보를 찾아보고, 요청하면 그 도구 안에서 직접 작업도 합니다. 면접을 만들고, 지원자 목록을 초대하고, 지난주 가장 높은 점수를 받은 사람이 누구인지 알려 주는 식입니다. Model Context Protocol(MCP)은 Claude나 ChatGPT처럼 이미 쓰고 있는 AI 채팅을 이런 도구에 연결해 주는 표준입니다. 그리고 API는 AI 없이 소프트웨어끼리 소통하는, 더 오래되고 더 정밀한 방법입니다.

이 가이드에서는 이 세 가지를 쉽게 설명하고, 채용에서 무엇에 유용한지, 무엇을 조심해야 하는지, 그리고 prepza에서 어떻게 쓰는지 알려 드립니다.

## AI 에이전트란

챗봇은 글만 씁니다. 에이전트는 **도구**를 가진 언어 모델입니다. 도구란 "이 면접의 지원자 목록 보기"나 "이 이메일 초대하기"처럼, 에이전트가 호출할 수 있는 작고 명확한 동작입니다. 무언가를 물으면 에이전트는 어떤 도구를 쓸지 정하고, 도구가 돌려준 결과를 읽은 뒤, 기억이 아니라 그 결과를 바탕으로 답합니다.

| 챗봇 | AI 에이전트 |
| --- | --- |
| 학습한 내용을 바탕으로 답한다 | 도구로 읽어 온 실시간 데이터를 바탕으로 답한다 |
| 방법을 설명하는 것만 할 수 있다 | 요청하고 허용하면 직접 할 수 있다 |
| 모르면 추측한다 | 찾아보거나, 할 수 없다고 말한다 |
| 하나의 창 안에만 있다 | 연결한 도구 안에서 일한다 |

에이전트를 유용하게 만드는 것도 도구이고, 안전한지 위험한지를 가르는 것도 도구입니다. 좋은 에이전트는 주어진 도구만, 사용자의 권한 안에서만 쓰고, 요청받은 일만 합니다.

## MCP란

Model Context Protocol은 Anthropic이 2024년 말에 공개한 개방형 표준으로, 지금은 Claude와 ChatGPT를 비롯한 많은 AI 앱과 개발자 도구가 지원합니다. 흔히 AI를 위한 USB-C 포트에 비유됩니다. AI 앱마다 도구마다 따로 연결을 만드는 대신, 도구가 **MCP 서버** 하나를 제공하면 MCP를 지원하는 어떤 AI 앱이든 그 도구를 쓸 수 있습니다.

MCP 서버는 AI 앱에 세 가지를 알려 줍니다.

1. **어떤 도구가 있는지.** 이름, 설명, 각 도구에 필요한 정보입니다.
2. **어떤 도구가 읽기만 하는지,** 어떤 도구가 무언가를 바꾸는지. 그래서 AI 앱은 변경 전에 사용자에게 물어볼 수 있습니다.
3. **사용자가 누구인지.** 한 번 승인하는 로그인을 통해 알려 주며, 모든 호출이 사용자 본인으로서, 본인의 권한으로 실행됩니다.

즉, 창 사이에서 데이터를 복사하지 않고도 이미 쓰고 있는 채팅에서 도구를 다룰 수 있다는 뜻입니다.

## API란, 그리고 무엇이 다른가

API(애플리케이션 프로그래밍 인터페이스)는 한 프로그램이 다른 프로그램에 보낼 수 있는 정해진 요청의 모음입니다. "이 면접의 지원자 목록 보기", "이 이메일 초대하기" 같은 것들입니다. 이 요청을 보내는 코드는 개발자가 작성합니다. AI는 관여하지 않습니다. 같은 요청은 항상 같은 일을 하며, 사람 없이 돌아가는 자동화에 바로 그런 점이 필요합니다.

| | AI 어시스턴트 미라(앱 안에서) | MCP(Claude나 ChatGPT에서) | API |
| --- | --- | --- | --- |
| 누가 쓰나 | 사용자 본인, prepza에서 | 사용자 본인, AI 채팅에서 | 자체 플랫폼의 코드 |
| 요청 방법 | 평소 쓰는 말로 | 평소 쓰는 말로 | 개발자가 작성한 정해진 요청 |
| 변경 승인 | 사용자 본인, 카드에서 | 사용자 본인, AI 앱에서 | 작성된 대로의 코드 |
| 적합한 용도 | 간단한 질문과 작업 | prepza를 다른 도구, 파일과 함께 쓰기 | 아무도 지켜보지 않아도 돌아가는 자동화 |
| 로그인 주체 | 사용자 본인 | 사용자 본인 | 회사 키 |

사람이 과정에 참여할 때는 미라나 MCP를 쓰세요. 채용 사이트나 사내 HR 도구처럼 자체 시스템이 스스로 지원자를 초대하고 결과를 모아야 할 때는 API를 쓰세요.

## 채용에서 무엇에 유용한가

채용에는 여러 도구에 흩어진 작고 반복적인 단계가 많습니다. 에이전트는 바로 그런 일에 강합니다.

- **채용 현황에 관한 질문.** "이번 주에 Senior Backend 면접에 합격한 지원자는?", "아직 면접을 시작하지 않은 사람은?", "데이터 분석가 직무의 평균 등급은?"
- **설정 작업.** "이 채용 공고로 면접을 만들어 줘", "합격 기준을 70%로 바꿔 줘", "이 지원자에게 시간을 50% 더 줘."
- **대량 작업.** 이메일이나 스프레드시트에서 그대로 붙여 넣은 "이 12명을 프론트엔드 면접에 초대해 줘."
- **여러 정보 결합.** Claude나 ChatGPT에서는 prepza를 다른 연결된 도구, 파일과 함께 쓸 수 있습니다. 문서에 있는 채용 공고와 면접 주제를 비교하거나, 최종 후보에 오른 지원자에게 보낼 메시지 초안을 쓸 수 있습니다.

에이전트가 해서는 안 되는 일은 채용 결정입니다. 등급은 사람의 판단을 돕는 것이지, 대신하는 것이 아닙니다. 정렬, 요약, 준비는 에이전트에게 맡기고, 결정은 사람이 내리세요. 이것이 법적으로도 왜 중요한지는 [EU에서 AI 채용은 합법일까?](/guides/is-ai-hiring-legal-in-the-eu)를 참고하세요.

## 조심해야 할 점

AI를 채용 데이터에 연결할 때는 동료에게 접근 권한을 줄 때만큼 신경 써야 합니다.

| 위험 | 도움이 되는 것 |
| --- | --- |
| 에이전트가 의도하지 않은 일을 한다 | 변경은 먼저 사용자의 승인이 필요하고, 요청받은 일만 한다 |
| 봐서는 안 되는 것까지 본다 | 사용자 본인으로서 동작한다. 사용자가 보는 것만 보고, 그 이상은 보지 않는다 |
| 데이터에 숨겨진 지시 | 지원자의 이름, 답변, 문서는 데이터일 뿐, 따라야 할 지시가 아니다 |
| 비밀 정보가 채팅에 들어간다 | API 키와 비밀번호는 절대 채팅을 거치지 않는다 |
| 되돌릴 수 없는 실수 | 계정이나 회사 삭제는 앱에서만, 별도의 확인을 거쳐 할 수 있다 |
| 데이터가 도구 밖으로 나간다 | 데이터는 연결한 AI 앱에 그 앱의 약관에 따라 전달된다. 회사가 허용한 앱만 연결한다 |
| 과도한 사용 | 시간당 실행할 수 있는 작업 수에 한도가 있다 |

업무 데이터에 AI 앱을 연결하기 전에 AI 도구에 관한 회사 정책을 확인하고, 개인정보 처리방침에서 어떤 서비스가 지원자의 데이터를 처리하는지 지원자에게 알리세요.

## 화면 밖에서 prepza를 쓰는 세 가지 방법

### 1. 내장 AI 어시스턴트 미라

어느 페이지에서든 상단의 **미라에게 묻기**를 선택하세요. prepza의 AI 어시스턴트 미라는 사용자의 회사, 면접, 지원자, 크레딧, 연동은 물론 prepza가 어떻게 작동하는지도 알고 있습니다. 사용자의 언어로 답하며, 입력하거나 말로 물어볼 수 있습니다.

- **사용자의 데이터를 바탕으로 답합니다.** 보는 범위도 사용자와 같습니다. 관리자에게는 관리자가 보는 것을, 뷰어에게는 뷰어가 보는 것을 보여 줍니다.
- **지금 있는 페이지를 압니다.** "이 페이지에서 무엇을 할 수 있나요?"라고 물으면 그 페이지의 가이드를 보여 주고, 면접의 지원자 페이지에서 "여기서 누가 가장 뛰어난가요?"라고 물으면 어느 면접인지 되묻지 않고 그 면접에 대해 답합니다.
- **변경은 에이전트가 준비하고, 확정은 사용자가 합니다.** 지원자 초대를 요청하면 "Backend developer에 지원자 12명 초대"처럼 무엇이 일어날지 정확히 보여 주는 카드가 나타납니다. "확인"을 선택하기 전에는 아무것도 실행되지 않습니다.
- **출처를 보여 줍니다.** 답변 아래에 참고한 지원자나 면접, 그리고 그 정보가 있는 페이지 링크가 표시됩니다.
- **주제에서 벗어나지 않습니다.** prepza와 prepza를 활용한 채용에 관해서만 답하고, 그 밖의 질문은 정중히 거절합니다.

### 2. MCP로 Claude나 ChatGPT에서 prepza 쓰기

팀이 이미 Claude나 ChatGPT로 일하고 있다면, 그곳에서 prepza를 쓸 수 있습니다. prepza의 MCP 서버는 내장 어시스턴트 미라와 같은 도구를 제공합니다.

**연결 방법:**

1. prepza에서 회사의 **연동** 탭을 열고 **AI 앱**을 선택합니다. 서버 주소 `https://prepza.ai/mcp`를 복사합니다.
2. **Claude:** 설정에서 커넥터를 열고, 그 주소로 사용자 지정 커넥터를 추가합니다. **Claude Code:** `claude mcp add --transport http prepza https://prepza.ai/mcp`를 실행합니다. **ChatGPT:** 앱 및 커넥터 설정에서 사용자 지정 커넥터로 추가합니다.
3. AI 앱이 prepza 로그인 페이지를 엽니다. 로그인하고, 어떤 앱이 요청하는지 확인한 뒤 **허용**을 선택합니다. 읽기만 허용하려면 먼저 **변경 허용**을 끕니다.

이제 동료에게 묻듯 채팅에서 물어보면 됩니다. "prepza에서 Product designer 면접 상위 지원자 3명은 누구야?" 대부분의 AI 앱은 변경하기 전에 먼저 확인을 받고, 되돌릴 수 없는 작업 전에는 경고합니다. 어떤 작업이 무언가를 변경하거나 삭제하는지는 prepza가 앱에 알려 줍니다.

**앱 안에서와 똑같이 유지되는 것:**

- **권한.** 사용자 본인으로서, 소속된 모든 회사에서, 각 회사에서의 역할대로 동작합니다.
- **크레딧과 한도.** 지원자 초대 비용은 앱 안에서와 같고, 이메일 한도도 똑같이 적용됩니다.
- **기록.** AI 앱이 사용자를 대신해 한 모든 일은 주제 승인과 결과 열람부터 추가 시간 부여나 지원자 철회까지 회사의 작업 기록에 AI 앱을 통해 한 것으로 표시됩니다. 회사 소유자는 회사의 **작업 기록** 탭에서 볼 수 있습니다.
- **결정은 회사가 합니다.** 소유자와 관리자는 회사의 AI 앱 페이지에서 **이 회사에서 AI 앱 허용**으로 AI 앱이 회사 데이터를 쓰지 못하게 할 수 있습니다.
- **할 수 없는 일.** 비밀번호나 API 키는 볼 수 없고, 계정이나 회사를 삭제할 수도 없습니다. 이런 일은 앱 안에서만 할 수 있습니다.

**연결을 끊으려면** AI 앱에서 커넥터를 삭제하거나, 연동 탭의 **AI 앱**에서 해당 앱 옆의 **연동 해제**를 선택하세요. 즉시 작동이 멈춥니다.

**다른 앱과 직접 만든 에이전트.** 개발자 문서의 [MCP 탭](/api-docs?tab=mcp)에 Gemini CLI, Cursor, VS Code, Le Chat 연결 방법과 Python 및 TypeScript로 된 완전한 예제 에이전트가 있습니다. 로그인을 승인할 사람이 없는 서버에서 실행되는 에이전트는 **AI 에이전트에서 사용 (MCP)** 권한이 있는 회사 API 키를 사용합니다. 이 키는 해당 회사에서만, 그리고 키의 다른 권한이 허용하는 도구로만 작동합니다. 에이전트가 한 일은 회사의 작업 기록에 키 이름으로 표시됩니다.

### 3. API로 자체 플랫폼에서 쓰기

AI 없는 자동화를 위해 prepza는 API를 제공하며, 자세한 내용은 [개발자 문서](/api-docs)에 있습니다.

1. 소유자나 관리자가 회사의 **연동** 탭을 열고 **API**에서 **새 키**를 선택합니다. 키를 사용할 플랫폼의 이름을 붙이고, 만료 시점을 고르고, 필요한 것만 선택하세요. 대시보드용 키는 조회만 하고, 채용 사이트용 키는 초대도 합니다. 권한은 나중에 추가하거나 뺄 수 있습니다. 키는 한 번만 표시되니 안전한 곳에 보관하세요.
2. 자체 플랫폼이 그 키로 요청을 보냅니다. 회사의 면접 목록을 보고, 지원자 목록이나 상세 정보를 등급, 합격 여부, 부정행위 신호와 함께 조회하고, 지원자를 초대할 수 있습니다.
3. **웹훅**을 추가하세요. 지원자가 응시를 시작하거나 마칠 때, 초대가 전달되지 않거나 만료될 때, 지원자가 삭제될 때, 그리고 면접이 준비되었을 때 prepza가 서명된 요청을 보내는 자체 플랫폼의 주소입니다. 그러면 계속 확인 요청을 보낼 필요가 없습니다. API 페이지에서 웹훅에 테스트 이벤트를 보낼 수 있고, 전송 기록도 확인할 수 있습니다.

각 지원자 정보에는 prepza의 전체 결과 링크와, 응시를 마치기 전까지는 본인 전용 초대 링크도 함께 제공됩니다. 원한다면 자체 플랫폼이 자체 메시지로 초대 링크를 보낼 수 있습니다. 자체 플랫폼이 이미 지원자가 누구인지 알고 있다면 로그인 없이 초대하세요. prepza는 이메일을 보내지 않고, 지원자는 prepza에 로그인하지 않고 링크로 면접을 보므로 링크는 그 지원자에게만 보내세요. 초대에는 완료 페이지에 귀사 사이트(어떤 https 주소든 가능)로 돌아가는 버튼을 넣을 수도 있고, 회사 색상으로 밝은 테마나 어두운 테마를 지정할 수도 있습니다. prepza SDK를 사용하면 자체 페이지에서 면접 자체를 보여줄 수 있지만, 회사가 API 페이지에서 허용한 사이트에서만 가능합니다. API와 웹훅은 이 사이트들과 관계없이 작동하며, 대신 각 키를 귀사 서버의 IP 주소에서만 쓸 수 있도록 제한할 수 있습니다. 인증은 인증 배지만 추가합니다.

다른 모든 곳과 같은 원칙이 적용됩니다. 등급은 사람의 결정을 돕는 것이므로, 등급만으로 지원자를 자동 불합격시키지 마세요.

## 언제 무엇을 쓸까

누가, 얼마나 자주 작업하는지부터 생각하세요.

| 상황 | 사용할 것 |
| --- | --- |
| prepza를 쓰다가 빠른 답이 필요할 때: 누가 합격했는지, 누가 아직 시작하지 않았는지, 크레딧이 얼마나 남았는지 | 내장 어시스턴트 미라 |
| 몇 마디로 설정하고 싶을 때: 채용 공고로 면접 만들기, 합격 기준, 추가 시간 | 내장 어시스턴트 미라 |
| 하루 종일 Claude나 ChatGPT로 일하고 있어서 그곳에서도 prepza를 쓰고 싶을 때 | MCP |
| prepza와 다른 것이 함께 필요한 작업: 문서, 이메일 초안, 다른 연결된 도구 | MCP |
| 이동 중인 리크루터가 휴대폰의 AI 앱으로 채용 현황을 확인하고 싶을 때 | MCP |
| 채용 사이트나 HR 시스템이 아무도 클릭하지 않아도 스스로 지원자를 초대해야 할 때 | API |
| 지원자가 응시를 마치는 즉시 결과가 자체 데이터베이스나 대시보드에 들어와야 할 때 | API와 웹훅 |
| 사용하는 ATS가 prepza와 연동되는 ATS(Workable, Greenhouse, Teamtailor, Recruitee, Breezy HR)일 때 | 셋 다 아닙니다. 연동 탭에서 ATS를 연결하세요. [역량 테스트를 ATS와 연동하는 방법](/guides/ats-integration-skills-tests)을 참고하세요 |

간단한 기준은 다음과 같습니다.

- **사람이 묻고, 변경을 하나하나 확인할 때:** prepza의 미라. 그 사람이 주로 Claude나 ChatGPT에서 일한다면 MCP.
- **소프트웨어가 스스로, 매번 같은 방식으로 동작할 때:** API.
- **처음 시작할 때:** 먼저 내장 어시스턴트 미라를 써 보세요. 설정이 필요 없고, 여기서 익힌 것은 MCP에서도 그대로 쓸 수 있습니다.

함께 쓸 수도 있습니다. 팀은 HR 시스템에서 API로 초대를 보내고, 리크루터는 미라나 AI 채팅에 결과를 물어보는 식입니다.

## 좋은 결과를 얻는 요령

- **이름으로 지정하세요.** "그 면접"보다 "Senior Backend 면접"이 더 잘 통합니다.
- **중요한 일은 한 번에 한 단계씩 요청하세요.** 결과를 확인한 뒤 다음 단계를 요청하세요.
- **허용하기 전에 승인 내용을 읽으세요.** 무엇이 실행될지 정확히 보여 줍니다.
- **숫자의 출처를 물어보세요.** 좋은 에이전트는 그 숫자의 근거가 된 지원자나 페이지를 보여 줄 수 있습니다.
- **결정은 사람이 내리세요.** 에이전트는 찾고, 정렬하고, 준비하는 데 쓰고, 결정은 직접 내리세요.
