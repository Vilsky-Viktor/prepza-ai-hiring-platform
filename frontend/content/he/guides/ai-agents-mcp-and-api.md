# סוכני AI,‏ MCP ו-API: מה הם ואיך להשתמש בהם בגיוס

רוב האנשים הכירו AI לראשונה כחלון צ'אט: שואלים, והוא עונה. סוכן AI הולך צעד אחד קדימה. הוא יכול לחפש מידע בכלים שלכם, וכשאתם מבקשים, גם לעשות בהם דברים: ליצור ראיון, להזמין רשימת מועמדים, לספר לכם מי קיבל את הציון הגבוה ביותר בשבוע שעבר. Model Context Protocol (MCP) הוא התקן שמאפשר לצ'אט ה-AI שאתם כבר משתמשים בו, כמו Claude או ChatGPT, להתחבר לכלים כאלה. ו-API היא הדרך הוותיקה והמדויקת יותר שבה תוכנה מדברת עם תוכנה, בלי AI באמצע.

המדריך הזה מסביר את שלושתם בפשטות: במה הם עוזרים בגיוס, ממה כדאי להיזהר ואיך להשתמש בהם עם testee.

## מה זה סוכן AI

צ'אטבוט רק כותב טקסט. סוכן הוא מודל שפה עם **כלים**: פעולות קטנות ומוגדרות היטב שהוא רשאי להפעיל, כמו "הצג את המועמדים של הראיון הזה" או "הזמן את כתובת המייל הזו". כששואלים אותו משהו, הסוכן מחליט באילו כלים להשתמש, קורא את מה שהם מחזירים ועונה על סמך זה, לא מהזיכרון.

| צ'אטבוט | סוכן AI |
| --- | --- |
| עונה ממה שלמד באימון | עונה מהנתונים העדכניים שלכם, שהוא קורא דרך כלים |
| יכול רק להסביר איך עושים משהו | יכול לעשות את זה, כשאתם מבקשים ומאשרים |
| מנחש כשהוא לא יודע | בודק, או אומר שהוא לא יכול |
| חי בחלון אחד | עובד בתוך הכלים שאתם מחברים אליו |

הכלים הם מה שהופך סוכן לשימושי, והם גם מה שהופך אותו לבטוח או לא בטוח. סוכן טוב יכול להשתמש רק בכלים שקיבל, רק עם ההרשאות שלכם, ועושה רק את מה שביקשתם.

## מה זה MCP

Model Context Protocol הוא תקן פתוח ש-Anthropic השיקה בסוף 2024, וכיום Claude,‏ ChatGPT ועוד אפליקציות AI וכלי פיתוח רבים תומכים בו. משווים אותו לא פעם לחיבור USB-C של עולם ה-AI: במקום שכל אפליקציית AI תבנה חיבור משלה לכל כלי, הכלי מציע **שרת MCP** אחד, וכל אפליקציית AI שתומכת ב-MCP יכולה להשתמש בו.

שרת MCP אומר לאפליקציית ה-AI שלושה דברים:

1. **אילו כלים קיימים**, עם שם, תיאור והפרטים שכל אחד מהם צריך.
2. **אילו כלים רק קוראים** ואילו משנים משהו, כדי שאפליקציית ה-AI תוכל לשאול אתכם לפני שינוי.
3. **מי אתם**, דרך כניסה שאתם מאשרים פעם אחת, כך שכל פעולה רצה בשמכם ועם ההרשאות שלכם.

בשבילכם זה אומר שאפשר לעבוד עם כלי מתוך הצ'אט שאתם כבר משתמשים בו, בלי להעתיק נתונים בין חלונות.

## מה זה API, ובמה הוא שונה

API (ממשק תכנות יישומים) הוא סט של בקשות קבועות שתוכנה אחת יכולה לשלוח לאחרת: "הצג את המועמדים של הראיון הזה", "הזמן את כתובת המייל הזו". המפתחים שלכם כותבים קוד ששולח אותן. אין כאן AI: אותה בקשה תמיד עושה את אותו הדבר, וזה בדיוק מה שרוצים באוטומציה שרצה מעצמה.

| | מירה, עוזרת ה-AI (באפליקציה) | MCP (ב-Claude או ב-ChatGPT) | API |
| --- | --- | --- | --- |
| מי משתמש בו | אתם, ב-testee | אתם, בצ'אט ה-AI שלכם | הקוד של הפלטפורמה שלכם |
| איך מבקשים | במילים שלכם | במילים שלכם | בקשות קבועות שמפתח כותב |
| מי מאשר שינויים | אתם, בכרטיס | אתם, באפליקציית ה-AI שלכם | הקוד שלכם, כפי שנכתב |
| הכי מתאים ל | שאלות ומשימות מהירות | שילוב של testee עם הכלים והקבצים האחרים שלכם | אוטומציה שרצה בלי שאף אחד משגיח |
| מתחבר בתור | אתם | אתם | מפתח של החברה |

השתמשו במירה או ב-MCP כשיש אדם שמעורב בתהליך. השתמשו ב-API כשהמערכת שלכם צריכה להזמין מועמדים ולאסוף תוצאות בעצמה, למשל מאתר המשרות שלכם או מכלי HR פנימי.

## במה זה עוזר בגיוס

גיוס מורכב מהמון צעדים קטנים וחוזרים שמפוזרים בין כלים שונים. סוכן טוב בדיוק בהם:

- **שאלות על תהליך הגיוס.** "אילו מועמדים ל-Senior Backend עברו השבוע?", "מי עוד לא התחיל את הראיון?", "מה הציון הממוצע שלנו למשרת אנליסט הדאטה?"
- **הגדרות.** "צור ראיון מתיאור המשרה הזה", "קבע את הציון העובר ל-70%", "תן למועמד הזה 50% זמן נוסף."
- **עבודה בכמויות.** "הזמן את 12 האנשים האלה לראיון פרונטאנד", כשהרשימה מודבקת ישר ממייל או מגיליון.
- **שילוב מקורות.** ב-Claude או ב-ChatGPT אפשר לשלב את testee עם כלים וקבצים אחרים שחיברתם: להשוות תיאור משרה מהמסמכים שלכם לנושאי הראיון, או לנסח הודעה למועמדים ברשימה הקצרה.

מה שהוא לא אמור לעשות הוא לקבל את החלטת הגיוס. ציון תומך בשיקול הדעת של אדם; הוא לא מחליף אותו. בקשו מהסוכן למיין, לסכם ולהכין, והשאירו את ההחלטה בידי אדם. ראו [האם גיוס עובדים בעזרת AI חוקי באיחוד האירופי?](/guides/is-ai-hiring-legal-in-the-eu) כדי להבין למה זה חשוב גם מבחינה משפטית.

## ממה כדאי להיזהר

חיבור AI לנתוני הגיוס שלכם דורש את אותה זהירות כמו מתן גישה לעמית.

| סיכון | מה עוזר |
| --- | --- |
| הסוכן עושה משהו שלא התכוונתם אליו | שינויים צריכים קודם את האישור שלכם, והוא עושה רק את מה שביקשתם |
| הוא רואה יותר ממה שצריך | הוא פועל בשמכם: רואה את מה שאתם רואים, לא יותר |
| הוראות שמוסתרות בנתונים | השמות, התשובות והמסמכים של המועמדים הם נתונים, אף פעם לא הוראות לביצוע |
| סודות מגיעים לצ'אט | מפתחות API וסיסמאות אף פעם לא עוברים דרך הצ'אט |
| טעויות בלתי הפיכות | מחיקת חשבון או חברה נשארת באפליקציה, מאחורי אישור משלה |
| נתונים יוצאים מהכלים שלכם | הנתונים מגיעים לאפליקציית ה-AI שאתם מחברים, לפי התנאים שלה: חברו רק אפליקציות שהחברה שלכם מתירה |
| שימוש שיוצא משליטה | מגבלות על מספר הפעולות שרצות בשעה |

לפני שאתם מחברים אפליקציית AI כלשהי לנתוני עבודה, בדקו את מדיניות החברה שלכם לגבי כלי AI, וספרו למועמדים בהודעת הפרטיות אילו שירותים מעבדים את הנתונים שלהם.

## שלוש דרכים לעבוד עם testee מעבר לעמודים שלה

### 1. מירה, עוזרת ה-AI המובנית

בחרו **לשאול את מירה** בכותרת של כל עמוד. מירה, עוזרת ה-AI של testee, מכירה את החברות, הראיונות, המועמדים, הקרדיטים והאינטגרציות שלכם, ויודעת איך testee עובדת. היא עונה בשפה שלכם, ואפשר להקליד או לדבר.

- **הוא עונה מהנתונים שלכם**, עם אותן הרשאות שיש לכם: מנהל רואה את מה שמנהל רואה, צופה את מה שצופה רואה.
- **הוא יודע באיזה עמוד אתם נמצאים.** שאלו "מה אפשר לעשות בדף הזה?" כדי לקבל את המדריך של אותו עמוד, או "מי הכי טוב כאן?" במועמדים של ראיון, והוא עונה על אותו ראיון בלי לשאול לאיזה ראיון הכוונה.
- **הוא מכין שינויים, ואתם מאשרים.** כשמבקשים ממנו להזמין מועמדים, הוא מציג כרטיס שמפרט בדיוק מה יקרה, למשל "הזמנת 12 מועמדים ל-Backend developer". שום דבר לא רץ עד שתבחרו "אישור".
- **הוא מראה את המקורות.** מתחת לתשובה מופיעים המועמדים או הראיונות שבהם השתמש וקישור לעמוד שממנו הגיעו.
- **הוא נשאר בנושא.** הוא עונה על testee ועל גיוס בעזרתה, ומסרב לכל השאר.

### 2. testee ב-Claude או ב-ChatGPT, דרך MCP

אם הצוות שלכם כבר עובד ב-Claude או ב-ChatGPT, אפשר להביא את testee לשם. שרת ה-MCP של testee מציע את אותם כלים כמו מירה, העוזרת המובנית.

**כדי להתחבר:**

1. ב-testee, פתחו את הלשונית **אינטגרציות** של חברה ובחרו **אפליקציות AI**. העתיקו את כתובת השרת: `https://testee.ai/mcp`.
2. **ב-Claude:** פתחו את ההגדרות, ואז Connectors, והוסיפו מחבר מותאם אישית עם הכתובת הזו. **ב-Claude Code:** הריצו `claude mcp add --transport http testee https://testee.ai/mcp`. **ב-ChatGPT:** הוסיפו אותה כמחבר מותאם אישית בהגדרות האפליקציות והמחברים.
3. אפליקציית ה-AI שלכם פותחת את דף הכניסה של testee. היכנסו, בדקו איזו אפליקציה מבקשת גישה ובחרו **מתן גישה**. כדי שתוכל רק לקרוא, כבו קודם את **מתן הרשאה לשינויים**.

מעכשיו, שאלו בצ'אט כמו שהייתם שואלים עמית: "ב-testee, מי שלושת המועמדים המובילים ל-Product designer?" רוב אפליקציות ה-AI שואלות אתכם לפני שינוי ומזהירות לפני כל דבר שאי אפשר לבטל: testee מציינת להן אילו פעולות משנות או מוחקות משהו.

**מה נשאר כמו באפליקציה:**

- **ההרשאות שלכם.** הוא פועל בשמכם, בכל חברה שאתם חברים בה, עם התפקיד שלכם בכל אחת.
- **קרדיטים ומגבלות.** הזמנת מועמד עולה אותו דבר כמו באפליקציה, וחלות אותן מגבלות מיילים.
- **התיעוד.** כל מה שאפליקציית AI עושה בשבילכם מופיע ביומן הפעולות של החברה כפעולה שנעשתה דרך אפליקציית AI, מאישור נושאים וצפייה בתוצאות ועד מתן זמן נוסף או ביטול מועמד. הבעלים של החברה קוראים אותו בלשונית **יומן פעולות** של החברה.
- **החברה מחליטה.** בעלים ומנהלים יכולים למנוע מאפליקציות AI להשתמש בנתוני החברה בעזרת **לאפשר אפליקציות AI בחברה הזו** בדף אפליקציות ה-AI שלה.
- **מה הוא לא יכול לעשות.** הוא לא יכול לראות את הסיסמה או את מפתחות ה-API שלכם, ולא יכול למחוק את החשבון שלכם או חברה. הפעולות האלה נשארות באפליקציה.

**כדי להתנתק,** הסירו את המחבר באפליקציית ה-AI, או בחרו **ניתוק** לידו תחת **אפליקציות AI** בלשונית אינטגרציות. הוא מפסיק לעבוד מיד.

**אפליקציות אחרות וסוכנים משלכם.** [לשונית MCP](/api-docs?tab=mcp) בתיעוד למפתחים כוללת את השלבים עבור Gemini CLI, Cursor, VS Code ו-Le Chat, וסוכנים לדוגמה מלאים ב-Python וב-TypeScript. סוכן שרץ על שרת, בלי אף אחד שיאשר התחברות, משתמש במפתח API של החברה עם ההרשאה **שימוש עם סוכני AI (MCP)**: הוא עובד רק בחברה הזו, ורק עם הכלים שההרשאות האחרות של המפתח מתירות. כל מה שהוא עושה מופיע ביומן הפעולות של החברה בשם המפתח.

### 3. הפלטפורמה שלכם, דרך ה-API

לאוטומציה בלי AI, ל-testee יש API, שמתואר [בתיעוד למפתחים](/api-docs) שלה.

1. בעלים או מנהל פותחים את הלשונית **אינטגרציות** של החברה, ואז **API**, ובוחרים **מפתח חדש**. תנו לו שם לפי הפלטפורמה שתשתמש בו, בחרו מתי יפוג וסמנו רק את מה שהוא צריך: מפתח של דשבורד רק קורא, ומפתח של אתר משרות גם מזמין. אפשר להוסיף או להסיר הרשאות בהמשך. המפתח מוצג פעם אחת בלבד; שמרו אותו במקום בטוח.
2. הפלטפורמה שלכם שולחת בקשות עם המפתח הזה: הצגת הראיונות של החברה, הצגת מועמדים או קריאת הפרטים של מועמד עם הציון שלו, האם עבר וסימני האזהרה לגבי טוהר המבחן, והזמנת מועמד.
3. הוסיפו **וובהוק**: כתובת בפלטפורמה שלכם ש-testee קוראת לה, בבקשה חתומה, כשמועמד מתחיל, מסיים או מוסר, כשההזמנה לא הגיעה אליו או שתוקפה פג, וכשראיון מוכן, כדי שלא תצטרכו לבדוק שוב ושוב. בדף ה-API אפשר לשלוח לו אירוע בדיקה ולראות את יומן המסירות שלו.

כל מועמד מגיע עם קישור לתוצאות המלאות שלו ב-testee, ועד שהוא מסיים, גם עם קישור ההזמנה האישי שלו, כך שהפלטפורמה שלכם יכולה לשלוח אותו בהודעה משלה אם תעדיפו. כשהפלטפורמה שלכם כבר יודעת מי המועמד, הזמינו אותו בלי התחברות: testee לא שולחת שום מייל, והמועמד עושה את הראיון מהקישור בלי להתחבר ל-testee, לכן שלחו את הקישור רק לו. הזמנה יכולה גם להחזיר את המועמד לאתר שלכם (כל כתובת https) בכפתור בעמוד הסיום, ולקבוע ערכת נושא בהירה או כהה בצבעי החברה שלכם. עם ה-SDK של testee, הדף שלכם יכול להציג את הראיון עצמו, אבל רק באתרים שהחברה שלכם מאשרת בדף ה-API שלה. ה-API והוובהוקים לא תלויים באתרים האלה: במקום זאת אפשר להגביל כל מפתח לכתובות ה-IP של השרתים שלכם. האימות רק מוסיף את תג החברה המאומתת.

אותו כלל חל כאן כמו בכל מקום: הציון תומך בהחלטה של אדם, אז אל תדחו מועמדים אוטומטית על סמך הציון.

## במה להשתמש ומתי

התחילו ממי שעושה את העבודה ובאיזו תדירות.

| המצב שלכם | השתמשו ב |

כלל אצבע פשוט:

- **אדם שואל ובודק כל שינוי:** מירה ב-testee, או MCP אם האדם הזה חי ב-Claude או ב-ChatGPT.
- **תוכנה פועלת לבד, באותו אופן בכל פעם:** ה-API.
- **בהתחלה:** נסו קודם את מירה, העוזרת המובנית. היא לא דורשת שום הגדרה, ומה שתלמדו יעזור לכם גם ב-MCP.

הם גם עובדים יחד. צוות יכול לשלוח הזמנות ממערכת ה-HR שלו דרך ה-API, בזמן שהמגייסים שואלים את מירה או את צ'אט ה-AI שלהם על התוצאות.

## איך לקבל תוצאות טובות

- **תנו שמות.** "הראיון של Senior Backend" עובד טוב יותר מ"הראיון ההוא".
- **בקשו צעד אחד בכל פעם** כשזה חשוב. בדקו את התוצאה, ואז בקשו את הצעד הבא.
- **קראו את בקשת האישור לפני שאתם מאשרים.** היא מראה בדיוק מה ירוץ.
- **שאלו מאיפה הגיע מספר.** סוכן טוב יכול להצביע על המועמדים או על העמוד שמאחוריו.
- **השאירו את ההחלטות בידי אנשים.** השתמשו בסוכן כדי למצוא, למיין ולהכין; את ההחלטה קבלו בעצמכם.
