# ИИ-агенты, MCP и API: что это такое и как использовать их в найме

Большинство людей впервые познакомились с ИИ в окне чата: вы спрашиваете, он отвечает. ИИ-агент идёт на шаг дальше. Он может находить информацию в ваших инструментах и по вашей просьбе выполнять в них действия: создать собеседование, пригласить список кандидатов, подсказать, у кого был самый высокий результат на прошлой неделе. Model Context Protocol (MCP) — это стандарт, который позволяет ИИ-чату, которым вы уже пользуетесь, например Claude или ChatGPT, подключаться к таким инструментам. А API — более старый и более точный способ, которым одна программа общается с другой, без ИИ посередине.

В этом руководстве простыми словами объясняется, что такое все три, чем они полезны в найме, чего стоит остерегаться и как использовать их с prepza.

## Что такое ИИ-агент

Чат-бот только пишет текст. Агент — это языковая модель с **инструментами**: небольшими чётко определёнными действиями, которые она может вызывать, например «показать кандидатов этого собеседования» или «пригласить этот email». Когда вы что-то спрашиваете, агент решает, какие инструменты использовать, читает, что они вернули, и отвечает на основе этого, а не по памяти.

| Чат-бот | ИИ-агент |
| --- | --- |
| Отвечает на основе того, чему научился при обучении | Отвечает по вашим актуальным данным, прочитанным через инструменты |
| Может только описать, как что-то сделать | Может сделать это сам, когда вы попросите и разрешите |
| Додумывает, когда не знает | Проверяет или говорит, что не может |
| Живёт в одном окне | Работает внутри инструментов, к которым вы его подключили |

Именно инструменты делают агента полезным — и именно от них зависит, безопасен он или нет. Хороший агент может использовать только выданные ему инструменты, только с вашими правами и делает только то, о чём вы попросили.

## Что такое MCP

Model Context Protocol — открытый стандарт, который Anthropic представила в конце 2024 года. Сейчас его поддерживают Claude, ChatGPT и многие другие ИИ-приложения и инструменты разработчиков. Его часто сравнивают с портом USB-C для ИИ: вместо того чтобы каждое ИИ-приложение строило своё подключение к каждому инструменту, инструмент предлагает один **MCP-сервер**, и любое ИИ-приложение, которое поддерживает MCP, может им пользоваться.

MCP-сервер сообщает ИИ-приложению три вещи:

1. **Какие инструменты есть** — с названием, описанием и данными, которые нужны каждому из них.
2. **Какие инструменты только читают,** а какие что-то меняют, чтобы ИИ-приложение могло спросить вас перед изменением.
3. **Кто вы** — через вход, который вы одобряете один раз, чтобы каждый вызов выполнялся от вашего имени и с вашими правами.

Для вас это значит, что можно работать с инструментом прямо из чата, которым вы уже пользуетесь, не копируя данные между окнами.

## Что такое API и чем он отличается

API (интерфейс программирования приложений) — это набор фиксированных запросов, которые одна программа может отправлять другой: «показать кандидатов этого собеседования», «пригласить этот email». Ваши разработчики пишут код, который их отправляет. ИИ здесь не участвует: один и тот же запрос всегда делает одно и то же, а это именно то, что нужно для автоматизации, которая работает сама.

| | ИИ-агент (в приложении) | MCP (в Claude или ChatGPT) | API |
| --- | --- | --- | --- |
| Кто пользуется | Вы, в prepza | Вы, в своём ИИ-чате | Код вашей платформы |
| Как вы просите | Своими словами | Своими словами | Фиксированными запросами, которые пишет разработчик |
| Кто одобряет изменения | Вы, на карточке | Вы, в своём ИИ-приложении | Ваш код, как он написан |
| Лучше всего для | Быстрых вопросов и задач | Работы с prepza вместе с другими инструментами и файлами | Автоматизации, которая работает без присмотра |
| Входит как | Вы | Вы | Ключ компании |

Используйте агента или MCP, когда в процессе участвует человек. Используйте API, когда ваша собственная система должна сама приглашать кандидатов и собирать результаты, например с карьерного сайта или из внутреннего HR-инструмента.

## Чем это полезно в найме

В найме много мелких повторяющихся шагов, разбросанных по разным инструментам. Агент хорошо справляется именно с ними:

- **Вопросы о воронке.** «Какие кандидаты на Senior Backend прошли на этой неделе?», «Кто ещё не начал собеседование?», «Какая у нас средняя оценка на роль аналитика данных?»
- **Настройка.** «Создай собеседование по этому описанию вакансии», «Установи проходной балл 70%», «Дай этому кандидату на 50% больше времени».
- **Массовые действия.** «Пригласи этих 12 человек на собеседование Frontend» — со списком, вставленным прямо из письма или таблицы.
- **Объединение источников.** В Claude или ChatGPT можно совмещать prepza с другими подключёнными инструментами и файлами: сравнить описание вакансии из ваших документов с темами собеседования или подготовить черновик письма кандидатам из шорт-листа.

Чего он делать не должен, так это принимать решение о найме. Оценка помогает человеку составить суждение, но не заменяет его. Поручайте агенту сортировать, обобщать и готовить, а решение оставляйте за человеком. О том, почему это важно и с юридической точки зрения, читайте в статье [Законен ли подбор персонала с ИИ в ЕС?](/guides/is-ai-hiring-legal-in-the-eu)

## Чего стоит остерегаться

Подключение ИИ к данным о найме требует той же осторожности, что и предоставление доступа коллеге.

| Риск | Что помогает |
| --- | --- |
| Агент делает не то, что вы имели в виду | Изменения сначала требуют вашего одобрения, и он делает только то, о чём вы попросили |
| Он видит больше, чем следует | Он действует от вашего имени: видит то же, что и вы, и не больше |
| Инструкции, спрятанные в данных | Имена, ответы и документы кандидатов — это данные, а не инструкции к исполнению |
| Секреты попадают в чат | API-ключи и пароли никогда не проходят через чат |
| Необратимые ошибки | Удаление аккаунта или компании остаётся в приложении, за отдельным подтверждением |
| Данные покидают ваши инструменты | Данные попадают в подключённое ИИ-приложение на условиях этого приложения: подключайте только те приложения, которые разрешает ваша компания |
| Неконтролируемое использование | Ограничения на число действий в час |

Прежде чем подключать любое ИИ-приложение к рабочим данным, проверьте политику вашей компании в отношении ИИ-инструментов и укажите в уведомлении о конфиденциальности для кандидатов, какие сервисы обрабатывают их данные.

## Три способа работать с prepza за пределами её страниц

### 1. Встроенный агент

Выберите **спросить агента** в шапке любой страницы. Агент знает ваши компании, собеседования, кандидатов, кредиты и интеграции, а также то, как устроена prepza. Он отвечает на вашем языке, а вопрос можно написать или произнести.

- **Он отвечает по вашим данным** и видит то же, что и вы: администратор видит то, что видит администратор, наблюдатель — то, что видит наблюдатель.
- **Он знает, на какой вы странице.** Спросите «Что можно сделать на этой странице?», чтобы получить руководство по этой странице, или «Кто здесь лучший?» на странице кандидатов собеседования, и он ответит об этом собеседовании, не уточняя, о каком речь.
- **Он готовит изменения, а вы их подтверждаете.** Если попросить его пригласить кандидатов, он покажет карточку с тем, что именно произойдёт, например «Пригласить 12 кандидатов на собеседование Backend-разработчик». Ничего не выполняется, пока вы не нажмёте «Подтвердить».
- **Он показывает источники.** Под ответом вы видите кандидатов или собеседования, на которые он опирался, и ссылку на страницу, откуда они взяты.
- **Он не отвлекается от темы.** Он отвечает о prepza и о найме с её помощью, а от остального отказывается.

### 2. prepza в Claude или ChatGPT через MCP

Если ваша команда уже работает в Claude или ChatGPT, prepza можно подключить туда. MCP-сервер prepza предлагает те же инструменты, что и встроенный агент.

**Как подключить:**

1. В prepza откройте вкладку **Интеграции** компании и выберите **ИИ-приложения**. Скопируйте адрес сервера: `https://prepza.ai/mcp`.
2. **В Claude:** откройте «Настройки», затем «Коннекторы» и добавьте пользовательский коннектор с этим адресом. **В Claude Code:** выполните `claude mcp add --transport http prepza https://prepza.ai/mcp`. **В ChatGPT:** добавьте его как пользовательский коннектор в настройках приложений и коннекторов.
3. Ваше ИИ-приложение откроет страницу входа prepza. Войдите, проверьте, какое приложение запрашивает доступ, и нажмите **Разрешить**. Чтобы приложение могло только читать, сначала выключите **Разрешить изменения**.

После этого просто спрашивайте в чате, как спросили бы коллегу: «Кто в prepza три лучших кандидата на продуктового дизайнера?» Большинство ИИ-приложений спрашивают вас перед изменением и предупреждают перед любым необратимым действием: prepza сообщает им, какие действия что-то меняют или удаляют.

**Что остаётся таким же, как в приложении:**

- **Ваши права.** Подключение действует от вашего имени во всех компаниях, где вы состоите, с вашей ролью в каждой.
- **Кредиты и лимиты.** Приглашение кандидата стоит столько же, сколько в приложении, и действуют те же лимиты на письма.
- **Журнал.** Всё, что ИИ-приложение делает за вас, отображается в журнале действий компании как сделанное через ИИ-приложение: от одобрения тем и просмотра результатов до предоставления дополнительного времени или отзыва кандидата. Владелец компании читает его на вкладке **Журнал действий** компании.
- **Решает компания.** Владельцы и администраторы могут запретить ИИ-приложениям использовать данные компании переключателем **Разрешить ИИ-приложения в этой компании** на её странице ИИ-приложений.
- **Чего подключение не может.** Оно не видит ваш пароль и API-ключи и не может удалить ваш аккаунт или компанию. Это остаётся в приложении.

**Чтобы отключить,** удалите коннектор в своём ИИ-приложении или нажмите **Отключить** рядом с ним в разделе **ИИ-приложения** на вкладке «Интеграции». Он сразу перестанет работать.

**Другие приложения и ваши собственные агенты.** На [вкладке MCP](/api-docs?tab=mcp) документации для разработчиков есть шаги для Gemini CLI, Cursor, VS Code и Le Chat, а также полные примеры агентов на Python и TypeScript. Агент, который работает на сервере, где некому подтвердить вход, использует API-ключ компании с правом **Использование с ИИ-агентами (MCP)**: он работает только в этой компании и только с теми инструментами, которые разрешают остальные права ключа.

### 3. Ваша собственная платформа через API

Для автоматизации без ИИ у prepza есть API, описанный в [документации для разработчиков](/api-docs).

1. Владелец или администратор открывает вкладку **Интеграции** компании, затем **API**, и нажимает **Новый ключ**. Назовите его по платформе, которая будет его использовать, выберите срок действия и отметьте только то, что ему нужно: ключ дашборда только читает, ключ карьерного сайта ещё и приглашает. Права можно потом отозвать, но не добавить. Ключ показывается один раз — сохраните его в надёжном месте.
2. Ваша платформа отправляет запросы с этим ключом: получает список собеседований компании, список кандидатов или данные отдельного кандидата с оценкой, информацией о том, прошёл ли он, и отметками о подозрительных действиях, а также приглашает кандидата.
3. Добавьте **вебхук**: адрес на вашей платформе, на который prepza отправляет подписанный запрос, когда кандидат начинает или заканчивает, когда приглашение до него не дошло или истекло, когда кандидата удалили и когда собеседование готово, — так не придётся постоянно опрашивать prepza. На странице API можно отправить на него тестовое событие и посмотреть его журнал доставки.

К каждому кандидату прилагается ссылка на его полные результаты в prepza, а пока он не закончил, — его личная ссылка-приглашение, чтобы ваша платформа при желании могла отправить её в своём письме. Если ваша платформа уже знает, кто кандидат, пригласите его без входа: prepza не отправляет никаких писем, а кандидат проходит собеседование по ссылке, не входя в prepza, поэтому отправляйте ссылку только ему. Приглашение также может вернуть кандидата на ваш сайт кнопкой на завершающей странице и задать светлую или тёмную тему в цветах вашей компании. С SDK prepza ваша собственная страница может показывать само собеседование. Для возврата кандидатов на ваш сайт и показа собеседования на нём нужна подтверждённая компания, и работает это только на домене её сайта.

Правило то же, что и везде: оценка помогает человеку принять решение, поэтому не отказывайте кандидатам автоматически на её основании.

## Что когда использовать

Начните с того, кто выполняет работу и как часто.

| Ваша ситуация | Что использовать |
| --- | --- |
| Вы в prepza и хотите быстро получить ответ: кто прошёл, кто не начал, сколько осталось кредитов | Встроенный агент |
| Вы хотите настроить что-то в двух словах: собеседование по описанию вакансии, проходной балл, дополнительное время | Встроенный агент |
| Вы и так весь день работаете в Claude или ChatGPT и хотите, чтобы prepza была там же | MCP |
| Для задачи нужна prepza и что-то ещё: ваши документы, черновики писем, другой подключённый инструмент | MCP |
| Рекрутер в дороге хочет проверить воронку из ИИ-приложения на телефоне | MCP |
| Ваш карьерный сайт или HR-система должны сами приглашать кандидатов, без чьих-либо нажатий | API |
| Результаты должны попадать в вашу базу данных или дашборд, как только кандидаты заканчивают | API с вебхуком |
| Ваша ATS — одна из тех, к которым подключается prepza (Workable, Greenhouse, Teamtailor, Recruitee, Breezy HR) | Ничего из этого: подключите ATS на вкладке «Интеграции». См. [Как подключить тесты навыков к ATS](/guides/ats-integration-skills-tests) |

Простое правило:

- **Человек спрашивает и проверяет каждое изменение:** агент в prepza или MCP, если этот человек живёт в Claude или ChatGPT.
- **Программа действует сама, каждый раз одинаково:** API.
- **Для начала:** попробуйте встроенного агента. Он не требует настройки, а опыт пригодится и в MCP.

Их можно использовать вместе. Команда может рассылать приглашения из своей HR-системы через API, а рекрутеры — спрашивать о результатах агента или свой ИИ-чат.

## Как получать хорошие результаты

- **Называйте вещи своими именами.** «Собеседование Senior Backend» работает лучше, чем «то собеседование».
- **Просите по одному шагу,** когда это важно. Проверьте результат, затем просите о следующем.
- **Прочитайте запрос на одобрение, прежде чем разрешить.** В нём точно указано, что будет выполнено.
- **Спрашивайте, откуда взялась цифра.** Хороший агент может показать кандидатов или страницу, на которых она основана.
- **Оставляйте решения людям.** Используйте агента, чтобы найти, отсортировать и подготовить; решайте сами.

## Цены

Встроенный агент, подключение по MCP и API бесплатны. Вы платите только за кандидатов, как и всегда: за каждого кандидата, который ответил хотя бы на один вопрос, без подписки. См. [цены](/pricing).
