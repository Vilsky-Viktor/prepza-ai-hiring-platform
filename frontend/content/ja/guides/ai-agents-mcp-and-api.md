# AI エージェント、MCP、API とは：採用での活用方法

多くの人が最初に触れた AI は、チャット画面でした。質問すると、答えが返ってきます。AI エージェントはそこから一歩進みます。あなたが使っているツールの中で情報を調べ、頼めばそのツールの中で作業もします。面接を作成する、候補者のリストを招待する、先週いちばん評価が高かったのは誰かを教える、といったことです。Model Context Protocol（MCP）は、Claude や ChatGPT など、すでに使っている AI チャットをこうしたツールにつなぐための標準です。そして API は、AI を介さずにソフトウェア同士がやり取りする、より昔からある、より厳密な方法です。

このガイドでは、この 3 つをわかりやすく説明し、採用で何に役立つのか、何に注意すべきか、そして prepza でどう使うのかを解説します。

## AI エージェントとは

チャットボットは文章を書くだけです。エージェントは、**ツール**を持った言語モデルです。ツールとは、「この面接の候補者を一覧にする」「このメールアドレスを招待する」のような、呼び出すことを許された小さく明確な操作のことです。何かを尋ねると、エージェントはどのツールを使うかを決め、その結果を読み、記憶ではなくその結果に基づいて答えます。

| チャットボット | AI エージェント |
| --- | --- |
| 学習した内容をもとに答える | ツールで読み取った最新のデータをもとに答える |
| やり方を説明することしかできない | 頼まれて許可されれば、実際に作業できる |
| わからないときは推測する | 調べるか、できないと答える |
| 1 つの画面の中だけで動く | 接続したツールの中で動く |

エージェントを役立つものにするのはツールであり、安全か危険かを決めるのもツールです。良いエージェントは、与えられたツールしか使えず、あなたの権限の範囲でしか動けず、頼まれたことしか行いません。

## MCP とは

Model Context Protocol は、Anthropic が 2024 年末に発表したオープンな標準で、今では Claude、ChatGPT をはじめ、多くの AI アプリや開発者向けツールが対応しています。よく AI 向けの USB-C ポートにたとえられます。AI アプリがそれぞれのツールと個別に接続を作るのではなく、ツール側が 1 つの **MCP サーバー**を用意すれば、MCP に対応したどの AI アプリからでも使えるようになります。

MCP サーバーは、AI アプリに次の 3 つを伝えます。

1. **どんなツールがあるか**。名前、説明、それぞれに必要な情報です。
2. **どのツールが読み取りだけで**、どのツールが何かを変更するか。これにより、AI アプリは変更の前にあなたに確認できます。
3. **あなたが誰か**。一度だけ承認するサインインを通じて伝えられ、すべての呼び出しがあなたとして、あなたの権限で実行されます。

つまり、ウィンドウ間でデータをコピーしなくても、いつも使っているチャットからツールを操作できるということです。

## API とは、何が違うのか

API（アプリケーション・プログラミング・インターフェース）は、あるプログラムが別のプログラムに送れる、決まった形のリクエストの集まりです。「この面接の候補者を一覧にする」「このメールアドレスを招待する」といったものです。それを送るコードは開発者が書きます。AI は関わりません。同じリクエストは常に同じ結果になり、それこそが無人で動く自動化に求められることです。

| | AI アシスタントのミラ（アプリ内） | MCP（Claude や ChatGPT から） | API |
| --- | --- | --- | --- |
| 使う人 | あなた（prepza で） | あなた（AI チャットで） | 自社のプラットフォームのコード |
| 頼み方 | 自分の言葉で | 自分の言葉で | 開発者が書いた決まったリクエスト |
| 変更を承認する人 | あなた（カード上で） | あなた（AI アプリで） | 書かれたとおりのコード |
| 向いている用途 | ちょっとした質問や作業 | prepza をほかのツールやファイルと組み合わせる | 誰も見ていなくても動く自動化 |
| サインインの単位 | あなた | あなた | 会社のキー |

人が関わる場面ではミラか MCP を使いましょう。採用サイトや社内の人事ツールなど、自社のシステムが自動で候補者を招待し、結果を集めるべき場面では API を使います。

## 採用で何に役立つか

採用には、複数のツールにまたがる小さな繰り返し作業がたくさんあります。エージェントが得意なのは、まさにそうした作業です。

- **選考状況についての質問。**「今週 Senior Backend で合格した候補者は？」「まだ面接を始めていないのは誰？」「データアナリスト職の平均評価は？」
- **設定作業。**「この求人票から面接を作成して」「合格ラインを 70% にして」「この候補者の時間を 50% 延長して」
- **まとめての作業。** メールやスプレッドシートからそのまま貼り付けて、「この 12 人をフロントエンドの面接に招待して」。
- **情報源の組み合わせ。** Claude や ChatGPT では、prepza をほかの接続済みツールやファイルと組み合わせられます。手元の文書にある求人票と面接のテーマを比べたり、選考に残った候補者へのメッセージの下書きを作ったりできます。

エージェントにさせてはいけないのは、採用の判断です。評価は人の判断を支えるものであり、置き換えるものではありません。並べ替え、要約、準備はエージェントに頼み、判断は人が行いましょう。それが法的にも重要な理由は、[EU で AI を使った採用は合法か？](/guides/is-ai-hiring-legal-in-the-eu)をご覧ください。

## 注意すべきこと

AI を採用データにつなぐときは、同僚にアクセス権を渡すときと同じ注意が必要です。

| リスク | 対策 |
| --- | --- |
| エージェントが意図しないことをする | 変更には事前の承認が必要で、頼まれたことしか行わない |
| 見るべきでないものまで見てしまう | あなたとして動作し、あなたが見られるもの以上は見ない |
| データに隠された指示 | 候補者の氏名、回答、書類はデータであり、従うべき指示としては扱わない |
| 機密情報がチャットに流れる | API キーやパスワードはチャットを通さない |
| 取り返しのつかないミス | アカウントや会社の削除はアプリでのみ行い、専用の確認がある |
| データがツールの外に出る | データは接続した AI アプリに、そのアプリの規約のもとで渡る。会社が認めているアプリだけを接続する |
| 使いすぎ | 1 時間あたりに実行できる操作の数に上限がある |

業務データに AI アプリをつなぐ前に、AI ツールに関する自社の方針を確認し、どのサービスが候補者のデータを処理するのかをプライバシーポリシーで候補者に伝えましょう。

## 画面の外で prepza を使う 3 つの方法

### 1. 組み込みの AI アシスタント、ミラ

どのページでも、ヘッダーの **ミラに質問** を選びます。prepza の AI アシスタントであるミラは、あなたの会社、面接、候補者、クレジット、連携、そして prepza の仕組みを把握しています。あなたの言語で答え、入力でも音声でも質問できます。

- **あなたのデータに基づいて答えます。** 見える範囲はあなたと同じです。管理者には管理者が見られるものが、閲覧者には閲覧者が見られるものが表示されます。
- **今いるページを把握しています。** 「このページで何ができますか？」と聞けばそのページのガイドを示し、面接の候補者のページで「ここで一番優秀なのは誰？」と聞けば、どの面接かを尋ねずにその面接について答えます。
- **変更はエージェントが準備し、あなたが確定します。** 候補者の招待を頼むと、「Backend developer に候補者 12 人を招待」のように、何が起きるかを正確に示したカードが表示されます。「確認」を選ぶまで何も実行されません。
- **情報源を示します。** 回答の下に、使った候補者や面接と、その元のページへのリンクが表示されます。
- **話題から外れません。** prepza と、prepza を使った採用について答え、それ以外はお断りします。

### 2. MCP で Claude や ChatGPT から prepza を使う

チームがすでに Claude や ChatGPT で仕事をしているなら、そこで prepza を使えます。prepza の MCP サーバーは、組み込みのアシスタントであるミラと同じツールを提供します。

**接続するには：**

1. prepza で会社の **連携** タブを開き、**AI アプリ** を選びます。サーバーのアドレス `https://prepza.ai/mcp` をコピーします。
2. **Claude の場合：** 設定を開き、コネクタからそのアドレスでカスタムコネクタを追加します。**Claude Code の場合：** `claude mcp add --transport http prepza https://prepza.ai/mcp` を実行します。**ChatGPT の場合：** アプリとコネクタの設定で、カスタムコネクタとして追加します。
3. AI アプリが prepza のサインイン画面を開きます。サインインし、どのアプリがアクセスを求めているかを確認して、**許可** を選びます。読み取りだけを許可するには、先に **変更を許可** をオフにします。

あとは、同僚に聞くようにチャットで尋ねるだけです。「prepza で、Product designer の上位 3 人の候補者は？」ほとんどの AI アプリは変更の前に確認を求め、元に戻せない操作の前には警告します。どの操作が何かを変更・削除するかは、prepza がアプリに伝えています。

**アプリ内と変わらないこと：**

- **権限。** あなたとして、所属しているすべての会社で、それぞれの会社でのあなたの役割に応じて動作します。
- **クレジットと上限。** 候補者の招待にかかるクレジットはアプリ内と同じで、メール送信の上限も同じです。
- **記録。** AI アプリがあなたの代わりに行ったことはすべて、AI アプリ経由で行われたものとして会社の操作ログに表示されます。トピックの承認や結果の閲覧から、延長時間の付与や候補者の取り消しまで含まれます。会社のオーナーは、会社の **操作ログ** タブで確認できます。
- **会社が決めます。** オーナーと管理者は、会社の AI アプリのページで **この会社で AI アプリを許可する** をオフにして、AI アプリによる会社データの利用を止められます。
- **できないこと。** パスワードや API キーは見られず、アカウントや会社を削除することもできません。それらはアプリ内でのみ行えます。

**接続を解除するには、** AI アプリでコネクタを削除するか、連携タブの **AI アプリ** で、そのアプリの横にある **接続を解除** を選びます。すぐに使えなくなります。

**ほかのアプリと独自のエージェント。** 開発者向けドキュメントの [MCP タブ](/api-docs?tab=mcp)に、Gemini CLI、Cursor、VS Code、Le Chat の手順と、Python と TypeScript で書かれた完全なエージェントの例があります。サーバーで動き、サインインを承認する人がいないエージェントは、**AI エージェントで使用 (MCP)** 権限を持つ会社の API キーを使います。このキーはその会社の中だけで、キーのほかの権限が許すツールだけを使えます。エージェントが行ったことは、会社の操作ログにキーの名前で表示されます。

### 3. API で自社のプラットフォームから使う

AI を使わない自動化のために、prepza には API があり、[開発者向けドキュメント](/api-docs)で説明しています。

1. 所有者または管理者が会社の **連携** タブを開き、**API** を選んで **新しいキー** を選びます。キーには使うプラットフォームの名前を付け、有効期限を選び、必要なものだけにチェックを入れます。ダッシュボード用のキーなら閲覧だけ、採用サイト用のキーなら招待も許可します。権限はあとから追加したり外したりできます。キーは一度しか表示されないので、安全な場所に保管してください。
2. 自社のプラットフォームが、そのキーを使ってリクエストを送ります。会社の面接の一覧、候補者の一覧や詳細（評価、合格かどうか、不正の兆候を含む）の取得、候補者の招待ができます。
3. **Webhook** を追加します。候補者が回答を開始・完了したとき、招待が届かなかったとき、招待の期限が切れたとき、削除されたとき、そして面接の準備ができたときに prepza が署名付きで呼び出す、自社プラットフォーム側のアドレスです。これで、何度も問い合わせる必要がなくなります。API ページからテストイベントを送信でき、配信ログも確認できます。

各候補者には、prepza での詳しい結果へのリンクと、回答を終えるまでは本人用の招待リンクが付いてきます。そのため、必要なら自社のプラットフォームから独自のメッセージで招待リンクを送れます。自社のプラットフォームで候補者が誰かすでに分かっている場合は、サインインなしで招待してください。prepza はメールを送らず、候補者は prepza にサインインせずにリンクから面接を受けるので、リンクは本人だけに送ってください。招待では、完了ページのボタンで候補者を自社サイト（任意の https アドレス）に戻したり、会社の色でライトテーマまたはダークテーマを設定したりすることもできます。prepza の SDK を使えば、自社のページに面接そのものを表示できますが、表示できるのは会社が API ページで許可したサイトだけです。API と Webhook はこれらのサイトに左右されません。代わりに、各キーを自社サーバーの IP アドレスからだけ使えるように制限できます。認証で追加されるのは認証済みバッジだけです。

ルールはほかと同じです。評価は人の判断を支えるものなので、評価だけで候補者を自動的に不採用にしないでください。

## どれをいつ使うか

誰が、どのくらいの頻度で作業するかから考えましょう。

| 状況 | 使うもの |
| --- | --- |
| prepza を開いていて、すぐに答えがほしい（誰が合格したか、誰がまだ始めていないか、クレジットの残りはどれくらいか） | 組み込みのアシスタント、ミラ |
| 一言で設定したい（求人票からの面接作成、合格ライン、時間の延長） | 組み込みのアシスタント、ミラ |
| 一日中 Claude や ChatGPT で仕事をしていて、そこでも prepza を使いたい | MCP |
| prepza とほかのもの（手元の文書、メールの下書き、ほかの接続済みツール）を組み合わせる作業 | MCP |
| 外出中の採用担当者が、スマートフォンの AI アプリから選考状況を確認したい | MCP |
| 採用サイトや人事システムが、誰もクリックせずに自動で候補者を招待するようにしたい | API |
| 候補者が回答を終えたらすぐに、結果を自社のデータベースやダッシュボードに取り込みたい | API と Webhook |
| 使っている ATS が prepza の連携先（Workable、Greenhouse、Teamtailor、Recruitee、Breezy HR）である | どれでもありません。連携タブで ATS を接続します。[スキルテストを ATS と連携する方法](/guides/ats-integration-skills-tests)をご覧ください |

簡単な目安は次のとおりです。

- **人が尋ね、変更を一つひとつ確認する：** prepza のミラ。その人が普段 Claude や ChatGPT で仕事をしているなら MCP。
- **ソフトウェアが自動で、毎回同じように動く：** API。
- **はじめて使う：** まずは組み込みのアシスタントであるミラを試しましょう。設定は不要で、そこで覚えたことは MCP でもそのまま使えます。

組み合わせて使うこともできます。チームは人事システムから API で招待を送り、採用担当者は結果についてミラや AI チャットに尋ねる、という使い方です。

## うまく使うコツ

- **名前で指定する。**「あの面接」より「Senior Backend の面接」のほうがうまくいきます。
- **重要なときは一度に 1 ステップずつ頼む。** 結果を確認してから、次を頼みましょう。
- **許可する前に承認内容を読む。** 何が実行されるかが正確に表示されます。
- **数字の出どころを尋ねる。** 良いエージェントは、その数字の元になった候補者やページを示せます。
- **判断は人が行う。** エージェントは探す、並べ替える、準備するために使い、判断は自分で行いましょう。

## 料金

ミラ、MCP 接続、API は無料で使えます。お支払いいただくのは、これまでどおり候補者の分だけです。1 問以上回答した候補者 1 人ごとの料金で、サブスクリプションはありません。[料金](/pricing)をご覧ください。
