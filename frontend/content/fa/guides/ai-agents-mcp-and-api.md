# عامل‌های هوش مصنوعی، MCP و API: چیستند و چطور در استخدام از آن‌ها استفاده کنیم

بیشتر ما هوش مصنوعی را اول به شکل یک پنجرهٔ چت شناختیم: می‌پرسید و جواب می‌دهد. عامل هوش مصنوعی (AI agent) یک قدم جلوتر می‌رود. می‌تواند در ابزارهای شما اطلاعات پیدا کند و، وقتی از او بخواهید، در همان ابزارها کاری انجام دهد: مصاحبه‌ای بسازد، فهرستی از متقاضیان را دعوت کند، یا بگوید هفتهٔ پیش چه کسی بالاترین نمره را گرفت. Model Context Protocol (MCP) استانداردی است که به چت هوش مصنوعی‌ای که همین حالا از آن استفاده می‌کنید، مثل Claude یا ChatGPT، امکان می‌دهد به چنین ابزارهایی وصل شود. و API راه قدیمی‌تر و دقیق‌تری است که نرم‌افزارها با آن با هم حرف می‌زنند، بی‌آنکه هوش مصنوعی در میان باشد.

این راهنما هر سه را به زبان ساده توضیح می‌دهد: در استخدام به چه کاری می‌آیند، به چه چیزهایی باید حواستان باشد و چطور با testee از آن‌ها استفاده کنید.

## عامل هوش مصنوعی چیست

چت‌بات فقط متن می‌نویسد. عامل هوش مصنوعی یک مدل زبانی است که **ابزار** دارد: کارهای کوچک و دقیقاً تعریف‌شده‌ای که می‌تواند اجرا کند، مثل «متقاضیان این مصاحبه را فهرست کن» یا «این ایمیل را دعوت کن». وقتی چیزی می‌پرسید، عامل تصمیم می‌گیرد از کدام ابزارها استفاده کند، نتیجهٔ آن‌ها را می‌خواند و بر اساس همان پاسخ می‌دهد، نه از حافظه‌اش.

| چت‌بات | عامل هوش مصنوعی |
| --- | --- |
| از چیزهایی پاسخ می‌دهد که در آموزش یاد گرفته | از داده‌های به‌روز شما پاسخ می‌دهد که از طریق ابزارها می‌خواند |
| فقط می‌تواند توضیح دهد یک کار چطور انجام می‌شود | می‌تواند آن کار را انجام دهد، وقتی بخواهید و اجازه دهید |
| وقتی نمی‌داند، حدس می‌زند | جست‌وجو می‌کند، یا می‌گوید نمی‌تواند |
| در یک پنجره محدود است | درون ابزارهایی کار می‌کند که به آن‌ها وصلش می‌کنید |

ابزارها همان چیزی‌اند که عامل را مفید می‌کنند، و همان چیزی که آن را امن یا ناامن می‌کنند. عامل خوب فقط از ابزارهایی استفاده می‌کند که به او داده شده، فقط با دسترسی‌های شما، و فقط کاری را می‌کند که خواسته‌اید.

## MCP چیست

Model Context Protocol یک استاندارد باز است که Anthropic اواخر ۲۰۲۴ معرفی کرد و حالا Claude، ChatGPT و بسیاری از اپ‌های هوش مصنوعی و ابزارهای توسعه‌دهندگان از آن پشتیبانی می‌کنند. اغلب آن را به درگاه USB-C برای هوش مصنوعی تشبیه می‌کنند: به جای اینکه هر اپ هوش مصنوعی اتصال جداگانه‌ای به هر ابزار بسازد، هر ابزار یک **سرور MCP** ارائه می‌دهد و هر اپ هوش مصنوعی که از MCP پشتیبانی کند می‌تواند از آن استفاده کند.

سرور MCP سه چیز را به اپ هوش مصنوعی می‌گوید:

1. **چه ابزارهایی وجود دارد**، با نام، توضیح و جزئیاتی که هر کدام لازم دارد.
2. **کدام ابزارها فقط می‌خوانند** و کدام چیزی را تغییر می‌دهند، تا اپ هوش مصنوعی پیش از هر تغییر از شما بپرسد.
3. **شما چه کسی هستید**، از طریق ورودی که یک بار تأییدش می‌کنید، تا هر درخواست به نام شما و با دسترسی‌های شما انجام شود.

برای شما یعنی می‌توانید از همان چتی که همیشه استفاده می‌کنید با یک ابزار کار کنید، بی‌آنکه داده‌ها را بین پنجره‌ها کپی کنید.

## API چیست و چه فرقی دارد

API (رابط برنامه‌نویسی نرم‌افزار) مجموعه‌ای از درخواست‌های ثابت است که یک برنامه می‌تواند برای برنامهٔ دیگری بفرستد: «متقاضیان این مصاحبه را فهرست کن»، «این ایمیل را دعوت کن». توسعه‌دهندگان شما کدی می‌نویسند که این درخواست‌ها را می‌فرستد. هوش مصنوعی در کار نیست: یک درخواست همیشه همان کار را انجام می‌دهد، و این دقیقاً همان چیزی است که برای خودکارسازی‌ای که خودش اجرا می‌شود می‌خواهید.

| | میرا، دستیار هوش مصنوعی (درون اپ) | MCP (در Claude یا ChatGPT) | API |
| --- | --- | --- | --- |
| چه کسی از آن استفاده می‌کند | شما، در testee | شما، در چت هوش مصنوعی خودتان | کد پلتفرم شما |
| چطور درخواست می‌کنید | با زبان خودتان | با زبان خودتان | درخواست‌های ثابتی که توسعه‌دهنده می‌نویسد |
| چه کسی تغییرات را تأیید می‌کند | شما، روی یک کارت | شما، در اپ هوش مصنوعی‌تان | کد شما، همان‌طور که نوشته شده |
| مناسب برای | پرسش‌ها و کارهای سریع | ترکیب testee با دیگر ابزارها و فایل‌هایتان | خودکارسازی‌ای که بدون نظارت کسی اجرا می‌شود |
| به نام چه کسی وارد می‌شود | شما | شما | کلید شرکت |

وقتی انسانی در جریان کار است، از میرا یا MCP استفاده کنید. وقتی سیستم خودتان باید خودش متقاضیان را دعوت کند و نتایج را جمع کند، مثلاً از بخش فرصت‌های شغلی سایتتان یا یک ابزار داخلی منابع انسانی، از API استفاده کنید.

## این‌ها در استخدام به چه کاری می‌آیند

استخدام پر از قدم‌های کوچک و تکراری است که میان ابزارهای مختلف پخش شده‌اند. عامل هوش مصنوعی دقیقاً در همین کارها خوب است:

- **پرسش دربارهٔ روند استخدام.** «کدام متقاضیان Senior Backend این هفته قبول شدند؟»، «چه کسی هنوز مصاحبه‌اش را شروع نکرده؟»، «میانگین نمرهٔ ما برای موقعیت تحلیلگر داده چقدر است؟»
- **راه‌اندازی کارها.** «از این شرح شغل یک مصاحبه بساز»، «نمرهٔ قبولی را ۷۰٪ کن»، «به این متقاضی ۵۰٪ وقت اضافه بده.»
- **کارهای گروهی.** «این ۱۲ نفر را به مصاحبهٔ فرانت‌اند دعوت کن»، با فهرستی که مستقیم از یک ایمیل یا صفحه‌گسترده چسبانده‌اید.
- **ترکیب منابع.** در Claude یا ChatGPT می‌توانید testee را با دیگر ابزارها و فایل‌های وصل‌شده‌تان ترکیب کنید: شرح شغلی را که در اسنادتان دارید با موضوع‌های مصاحبه مقایسه کنید، یا پیش‌نویس پیامی برای متقاضیان فهرست نهایی آماده کنید.

کاری که نباید بکند، گرفتن تصمیم استخدام است. نمره به قضاوت انسان کمک می‌کند؛ جای آن را نمی‌گیرد. از عامل بخواهید مرتب کند، خلاصه کند و آماده کند، و تصمیم را به یک انسان بسپارید. برای اینکه بدانید چرا این از نظر حقوقی هم مهم است، [آیا استخدام با هوش مصنوعی در اتحادیه اروپا قانونی است؟](/guides/is-ai-hiring-legal-in-the-eu) را ببینید.

## به چه چیزهایی باید حواستان باشد

وصل کردن هوش مصنوعی به داده‌های استخدامتان همان دقتی را می‌طلبد که دادن دسترسی به یک همکار.

| خطر | چه چیزی کمک می‌کند |
| --- | --- |
| عامل کاری می‌کند که منظورتان نبود | تغییرات اول به تأیید شما نیاز دارند و عامل فقط کاری را می‌کند که خواسته‌اید |
| بیش از حد لازم می‌بیند | به جای شما عمل می‌کند: همان چیزی را می‌بیند که شما می‌بینید، نه بیشتر |
| دستورهای پنهان در داده‌ها | نام‌ها، پاسخ‌ها و اسناد متقاضیان داده‌اند، هرگز دستوری برای اجرا نیستند |
| اطلاعات محرمانه سر از چت درمی‌آورد | کلیدهای API و رمزهای عبور هرگز از چت عبور نمی‌کنند |
| اشتباه‌های برگشت‌ناپذیر | حذف حساب یا شرکت فقط در اپ انجام می‌شود، با تأیید جداگانهٔ خودش |
| داده‌ها از ابزارهای شما بیرون می‌روند | داده‌ها طبق شرایط اپ هوش مصنوعی‌ای که وصل می‌کنید به آن می‌رسند: فقط اپ‌هایی را وصل کنید که شرکتتان اجازه می‌دهد |
| استفادهٔ مهارنشده | سقفی برای تعداد کارهایی که در هر ساعت اجرا می‌شوند |

پیش از وصل کردن هر اپ هوش مصنوعی به داده‌های کاری، سیاست شرکتتان دربارهٔ ابزارهای هوش مصنوعی را بررسی کنید و در اطلاعیهٔ حریم خصوصی به متقاضیان بگویید کدام سرویس‌ها داده‌هایشان را پردازش می‌کنند.

## سه راه برای کار با testee فراتر از صفحه‌هایش

### 1. میرا، دستیار هوش مصنوعی داخلی

در سربرگ هر صفحه، **از میرا بپرسید** را انتخاب کنید. میرا، دستیار هوش مصنوعی testee، شرکت‌ها، مصاحبه‌ها، متقاضیان، اعتبار و یکپارچه‌سازی‌های شما را می‌شناسد و می‌داند testee چطور کار می‌کند. به زبان شما پاسخ می‌دهد و می‌توانید تایپ کنید یا حرف بزنید.

- **از داده‌های شما پاسخ می‌دهد**، با همان دسترسی‌ای که شما دارید: مدیر همان چیزی را می‌بیند که یک مدیر می‌بیند و بیننده همان چیزی را که یک بیننده می‌بیند.
- **می‌داند در کدام صفحه هستید.** بپرسید «در این صفحه چه کارهایی می‌توانم انجام دهم؟» تا راهنمای همان صفحه را ببینید، یا در صفحهٔ متقاضیان یک مصاحبه بپرسید «اینجا چه کسی از همه بهتر است؟»، و دربارهٔ همان مصاحبه پاسخ می‌دهد، بی‌آنکه بپرسد کدام مصاحبه.
- **تغییرات را آماده می‌کند، شما تأییدشان می‌کنید.** اگر از او بخواهید متقاضیانی را دعوت کند، کارتی نشان می‌دهد که دقیقاً می‌گوید چه اتفاقی می‌افتد، مثل «دعوت ۱۲ متقاضی به Backend developer». تا «تأیید» را انتخاب نکنید، هیچ کاری اجرا نمی‌شود.
- **منابعش را نشان می‌دهد.** زیر هر پاسخ، متقاضیان یا مصاحبه‌هایی را که به کار برده و پیوندی به صفحه‌ای که از آن آمده‌اند می‌بینید.
- **از موضوع خارج نمی‌شود.** دربارهٔ testee و استخدام با آن پاسخ می‌دهد و به بقیهٔ پرسش‌ها جواب نمی‌دهد.

### 2. testee در Claude یا ChatGPT، از طریق MCP

اگر تیمتان همین حالا در Claude یا ChatGPT کار می‌کند، می‌توانید testee را به همان‌جا بیاورید. سرور MCP در testee همان ابزارهای میرا، دستیار داخلی، را ارائه می‌دهد.

**برای وصل کردن:**

1. در testee، زبانهٔ **یکپارچه‌سازی‌ها** را در صفحهٔ یک شرکت باز کنید و **اپ‌های هوش مصنوعی** را انتخاب کنید. نشانی سرور را کپی کنید: `https://testee.ai/mcp`.
2. **در Claude:** تنظیمات و سپس Connectors را باز کنید و با این نشانی یک کانکتور سفارشی اضافه کنید. **در Claude Code:** این فرمان را اجرا کنید: `claude mcp add --transport http testee https://testee.ai/mcp`. **در ChatGPT:** آن را در تنظیمات اپ‌ها و کانکتورها به‌عنوان کانکتور سفارشی اضافه کنید.
3. اپ هوش مصنوعی‌تان صفحهٔ ورود testee را باز می‌کند. وارد شوید، بررسی کنید کدام اپ درخواست دسترسی دارد و **اجازه دادن** را انتخاب کنید. اگر می‌خواهید فقط بتواند بخواند، پیش از آن **اجازهٔ تغییرات** را خاموش کنید.

از این به بعد، در چتتان همان‌طور بپرسید که از یک همکار می‌پرسید: «در testee، سه متقاضی برتر برای Product designer چه کسانی هستند؟» بیشتر اپ‌های هوش مصنوعی پیش از تغییر دادن چیزی از شما می‌پرسند و پیش از هر کار برگشت‌ناپذیری هشدار می‌دهند: testee به آن‌ها می‌گوید کدام کارها چیزی را تغییر می‌دهند یا حذف می‌کنند.

**آنچه مثل خود اپ testee می‌ماند:**

- **دسترسی‌های شما.** به جای شما عمل می‌کند، در هر شرکتی که عضوش هستید، با نقشی که در هر کدام دارید.
- **اعتبار و محدودیت‌ها.** دعوت یک متقاضی همان‌قدر هزینه دارد که در اپ، و همان سقف‌های ارسال ایمیل اعمال می‌شود.
- **ثبت سوابق.** هر کاری که یک برنامهٔ هوش مصنوعی برای شما انجام می‌دهد، در سابقهٔ اقدامات شرکت با برچسب «انجام‌شده از طریق یک برنامهٔ هوش مصنوعی» نمایش داده می‌شود، از تأیید موضوع‌ها و دیدن نتایج تا دادن زمان اضافه یا لغو دعوت یک متقاضی. مالک شرکت آن را در زبانهٔ **سابقهٔ اقدامات** شرکت می‌خواند.
- **تصمیم با شرکت است.** مالکان و مدیران می‌توانند با **اجازهٔ برنامه‌های هوش مصنوعی در این شرکت** در صفحهٔ برنامه‌های هوش مصنوعی شرکت، جلوی استفادهٔ این برنامه‌ها از داده‌های شرکت را بگیرند.
- **کارهایی که نمی‌تواند بکند.** رمز عبور یا کلیدهای API شما را نمی‌بیند و نمی‌تواند حساب شما یا یک شرکت را حذف کند. این کارها فقط در اپ انجام می‌شوند.

**برای قطع اتصال،** کانکتور را در اپ هوش مصنوعی‌تان حذف کنید، یا در زبانهٔ یکپارچه‌سازی‌ها، زیر **اپ‌های هوش مصنوعی**، کنار آن **قطع اتصال** را انتخاب کنید. فوراً از کار می‌افتد.

**اپ‌های دیگر و عامل‌های خودتان.** [زبانهٔ MCP](/api-docs?tab=mcp) در مستندات توسعه‌دهندگان مراحل Gemini CLI، Cursor، VS Code و Le Chat را دارد، به‌همراه نمونه‌عامل‌های کامل به Python و TypeScript. عاملی که روی سرور اجرا می‌شود و کسی آنجا نیست تا ورود را تأیید کند، از کلید API شرکت با دسترسی **استفاده با عامل‌های هوش مصنوعی (MCP)** استفاده می‌کند: فقط در همان شرکت کار می‌کند و فقط با ابزارهایی که دسترسی‌های دیگر کلید اجازه می‌دهند. هر کاری که انجام دهد، در سابقهٔ اقدامات شرکت با نام کلید نشان داده می‌شود.

### 3. پلتفرم خودتان، از طریق API

برای خودکارسازی بدون هوش مصنوعی، testee یک API دارد که در [مستندات توسعه‌دهندگان](/api-docs) شرح داده شده است.

1. مالک یا مدیر شرکت زبانهٔ **یکپارچه‌سازی‌ها** و سپس **API** را باز می‌کند و **کلید جدید** را انتخاب می‌کند. نام پلتفرمی را که از آن استفاده خواهد کرد رویش بگذارید، زمان انقضایش را انتخاب کنید و فقط چیزهایی را که لازم دارد تیک بزنید: کلید یک داشبورد فقط می‌خواند، کلید سایت فرصت‌های شغلی دعوت هم می‌کند. بعداً می‌توانید دسترسی‌ها را اضافه یا کم کنید. کلید فقط یک بار نمایش داده می‌شود؛ آن را جای امنی نگه دارید.
2. پلتفرم شما با آن کلید درخواست می‌فرستد: فهرست مصاحبه‌های شرکت، فهرست متقاضیان یا جزئیات هر کدام با نمره، قبول شدن یا نشدن و هشدارهای مربوط به صداقت در آزمون، و دعوت متقاضی.
3. یک **وب‌هوک** اضافه کنید: نشانی‌ای روی پلتفرم شما که testee وقتی متقاضی آزمون را شروع یا تمام می‌کند، دعوت به او نمی‌رسد، دعوتش منقضی می‌شود یا حذف می‌شود، و وقتی مصاحبه‌ای آماده می‌شود، با درخواستی امضاشده فراخوانی‌اش می‌کند، تا لازم نباشد مدام وضعیت را بپرسید. در صفحهٔ API می‌توانید برایش یک رویداد آزمایشی بفرستید و گزارش تحویلش را ببینید.

هر متقاضی همراه با پیوندی به نتایج کاملش در testee می‌آید و، تا وقتی آزمون را تمام نکرده، پیوند دعوت خودش را هم دارد، تا اگر ترجیح می‌دهید پلتفرمتان آن را در پیام خودش بفرستد. وقتی پلتفرمتان از قبل می‌داند متقاضی کیست، او را بدون ورود دعوت کنید: testee هیچ ایمیلی نمی‌فرستد و متقاضی بدون ورود به testee از طریق همان پیوند در مصاحبه شرکت می‌کند، پس پیوند را فقط برای خود او بفرستید. دعوت همچنین می‌تواند متقاضی را با دکمه‌ای در صفحهٔ پایان مصاحبه به سایت شما (هر نشانی https) برگرداند، و پوسته‌ای روشن یا تیره با رنگ‌های شرکتتان تعیین کند. با SDK مربوط به testee، صفحهٔ خود شما می‌تواند خود مصاحبه را نمایش دهد، اما فقط روی سایت‌هایی که شرکتتان در صفحهٔ API مجاز کرده است. API و وب‌هوک‌ها به این سایت‌ها وابسته نیستند: در عوض می‌توان هر کلید را به نشانی‌های IP سرورهایتان محدود کرد. تأیید فقط نشان شرکت تأییدشده را اضافه می‌کند.

همان قاعدهٔ همیشگی اینجا هم برقرار است: نمره به تصمیم انسان کمک می‌کند، پس متقاضیان را بر اساس آن خودکار رد نکنید.

## کدام را کی به کار ببریم

از اینجا شروع کنید که چه کسی کار را انجام می‌دهد و هر چند وقت یک بار.

| وضعیت شما | گزینهٔ مناسب |
| --- | --- |
| در testee هستید و جواب سریعی می‌خواهید: چه کسی قبول شد، چه کسی شروع نکرده، چقدر اعتبار مانده | میرا، دستیار داخلی |
| می‌خواهید با چند کلمه چیزی را راه بیندازید: مصاحبه‌ای از شرح شغل، نمرهٔ قبولی، وقت اضافه | میرا، دستیار داخلی |
| تمام روز در Claude یا ChatGPT کار می‌کنید و testee را هم همان‌جا می‌خواهید | MCP |
| کار به testee و چیز دیگری نیاز دارد: اسنادتان، پیش‌نویس ایمیل‌ها، ابزار وصل‌شدهٔ دیگری | MCP |
| کارشناس جذبی که بیرون از دفتر است می‌خواهد روند استخدام را از اپ هوش مصنوعی روی گوشی‌اش بررسی کند | MCP |
| سایت فرصت‌های شغلی یا سیستم منابع انسانی شما باید خودش متقاضیان را دعوت کند، بی‌آنکه کسی کلیک کند | API |
| نتایج باید به محض اینکه متقاضیان آزمون را تمام کردند به پایگاه داده یا داشبورد خودتان برسند | API، همراه با وب‌هوک |
| ATS شما یکی از آن‌هایی است که testee به آن وصل می‌شود (Workable، Greenhouse، Teamtailor، Recruitee، Breezy HR) | هیچ‌کدام: ATS را در زبانهٔ یکپارچه‌سازی‌ها وصل کنید. [چطور آزمون‌های مهارت را به ATS خود وصل کنیم](/guides/ats-integration-skills-tests) را ببینید |

یک قاعدهٔ سرانگشتی ساده:

- **یک انسان می‌پرسد و هر تغییر را بررسی می‌کند:** میرا در testee، یا MCP اگر آن فرد بیشتر وقتش را در Claude یا ChatGPT می‌گذراند.
- **نرم‌افزار خودش و هر بار به یک شکل عمل می‌کند:** API.
- **برای شروع:** اول میرا، دستیار داخلی، را امتحان کنید. به هیچ راه‌اندازی‌ای نیاز ندارد و آنچه یاد می‌گیرید در MCP هم به کارتان می‌آید.

این‌ها کنار هم هم کار می‌کنند. یک تیم می‌تواند دعوت‌ها را از سیستم منابع انسانی‌اش از طریق API بفرستد، در حالی که کارشناسان جذب دربارهٔ نتایج از میرا یا چت هوش مصنوعی‌شان می‌پرسند.

## چطور نتیجهٔ خوب بگیریم

- **نام ببرید.** «مصاحبهٔ Senior Backend» بهتر از «آن مصاحبه» جواب می‌دهد.
- **هر بار یک قدم بخواهید**، وقتی موضوع مهم است. نتیجه را بررسی کنید و بعد قدم بعدی را بخواهید.
- **درخواست تأیید را پیش از اجازه دادن بخوانید.** دقیقاً نشان می‌دهد چه چیزی اجرا می‌شود.
- **بپرسید یک عدد از کجا آمده.** عامل خوب می‌تواند متقاضیان یا صفحه‌ای را که پشت آن عدد است نشان دهد.
- **تصمیم را به انسان بسپارید.** از عامل برای پیدا کردن، مرتب کردن و آماده کردن استفاده کنید؛ تصمیم را خودتان بگیرید.

## قیمت‌گذاری

میرا، اتصال MCP و API رایگان‌اند. مثل همیشه فقط برای متقاضیان پرداخت می‌کنید: به‌ازای هر متقاضی که دست‌کم به یک پرسش پاسخ دهد، بدون اشتراک. [قیمت‌ها](/pricing) را ببینید.
