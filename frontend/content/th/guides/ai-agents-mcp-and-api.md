# เอเจนต์ AI, MCP และ API คืออะไร และใช้ในการสรรหาอย่างไร

คนส่วนใหญ่รู้จัก AI ครั้งแรกผ่านหน้าต่างแชต คุณถาม แล้วมันก็ตอบ เอเจนต์ AI ก้าวไปอีกขั้น มันค้นข้อมูลในเครื่องมือที่คุณใช้ได้ และเมื่อคุณขอ ก็ลงมือทำงานในเครื่องมือเหล่านั้นได้ด้วย เช่น สร้างการสัมภาษณ์ เชิญผู้สมัครทั้งรายชื่อ หรือบอกว่าใครได้คะแนนสูงสุดเมื่อสัปดาห์ที่แล้ว Model Context Protocol (MCP) คือมาตรฐานที่ทำให้แชต AI ที่คุณใช้อยู่แล้ว เช่น Claude หรือ ChatGPT เชื่อมต่อกับเครื่องมือแบบนี้ได้ ส่วน API คือวิธีที่เก่าแก่กว่าและแม่นยำกว่าที่ซอฟต์แวร์ใช้คุยกับซอฟต์แวร์ โดยไม่มี AI อยู่ตรงกลาง

คู่มือนี้อธิบายทั้งสามอย่างด้วยภาษาที่เข้าใจง่าย ว่าแต่ละอย่างมีประโยชน์อะไรในการสรรหา ต้องระวังอะไร และใช้กับ prepza อย่างไร

## เอเจนต์ AI คืออะไร

แชตบอตทำได้แค่เขียนข้อความ ส่วนเอเจนต์คือโมเดลภาษาที่มี**เครื่องมือ** ซึ่งเป็นการทำงานเล็ก ๆ ที่กำหนดไว้ชัดเจนและเอเจนต์เรียกใช้ได้ เช่น "แสดงรายชื่อผู้สมัครของการสัมภาษณ์นี้" หรือ "เชิญอีเมลนี้" เมื่อคุณถามอะไร เอเจนต์จะตัดสินใจว่าจะใช้เครื่องมือใด อ่านสิ่งที่เครื่องมือส่งกลับมา แล้วตอบจากข้อมูลนั้น ไม่ใช่จากความจำ

| แชตบอต | เอเจนต์ AI |
| --- | --- |
| ตอบจากสิ่งที่เรียนรู้ระหว่างการฝึก | ตอบจากข้อมูลจริงล่าสุดของคุณ ซึ่งอ่านผ่านเครื่องมือ |
| ทำได้แค่อธิบายวิธีทำ | ลงมือทำได้ เมื่อคุณขอและอนุญาต |
| เดาเมื่อไม่รู้ | ค้นหาข้อมูล หรือบอกว่าทำไม่ได้ |
| อยู่ในหน้าต่างเดียว | ทำงานในเครื่องมือที่คุณเชื่อมต่อไว้ |

เครื่องมือคือสิ่งที่ทำให้เอเจนต์มีประโยชน์ และก็เป็นสิ่งที่ตัดสินว่าเอเจนต์ปลอดภัยหรือไม่ เอเจนต์ที่ดีใช้ได้เฉพาะเครื่องมือที่ได้รับ ทำได้เฉพาะภายใต้สิทธิ์ของคุณ และทำเฉพาะสิ่งที่คุณขอเท่านั้น

## MCP คืออะไร

Model Context Protocol เป็นมาตรฐานเปิดที่ Anthropic เปิดตัวเมื่อปลายปี 2024 และตอนนี้ Claude, ChatGPT รวมถึงแอป AI และเครื่องมือสำหรับนักพัฒนาอีกมากมายรองรับแล้ว มักมีการเปรียบว่ามันเหมือนพอร์ต USB-C สำหรับ AI แทนที่แอป AI ทุกตัวจะต้องสร้างการเชื่อมต่อของตัวเองกับเครื่องมือทุกตัว เครื่องมือเพียงเปิด **เซิร์ฟเวอร์ MCP** หนึ่งตัว แล้วแอป AI ใดก็ตามที่รองรับ MCP ก็ใช้งานได้

เซิร์ฟเวอร์ MCP บอกแอป AI สามเรื่อง:

1. **มีเครื่องมืออะไรบ้าง** พร้อมชื่อ คำอธิบาย และข้อมูลที่แต่ละเครื่องมือต้องใช้
2. **เครื่องมือใดแค่อ่านข้อมูล** และเครื่องมือใดเปลี่ยนแปลงบางอย่าง เพื่อให้แอป AI ถามคุณก่อนจะเปลี่ยนแปลง
3. **คุณคือใคร** ผ่านการลงชื่อเข้าใช้ที่คุณอนุมัติเพียงครั้งเดียว ทุกการเรียกใช้จึงทำงานในนามของคุณ ด้วยสิทธิ์ของคุณ

สำหรับคุณ นี่หมายความว่าคุณทำงานกับเครื่องมือได้จากแชตที่ใช้อยู่แล้ว โดยไม่ต้องคัดลอกข้อมูลไปมาระหว่างหน้าต่าง

## API คืออะไร และต่างกันอย่างไร

API (application programming interface) คือชุดคำขอที่กำหนดไว้ตายตัว ซึ่งโปรแกรมหนึ่งส่งไปยังอีกโปรแกรมหนึ่งได้ เช่น "แสดงรายชื่อผู้สมัครของการสัมภาษณ์นี้" หรือ "เชิญอีเมลนี้" นักพัฒนาของคุณเป็นผู้เขียนโค้ดที่ส่งคำขอเหล่านี้ ไม่มี AI เกี่ยวข้อง คำขอเดียวกันจะทำสิ่งเดียวกันเสมอ ซึ่งเป็นสิ่งที่ระบบอัตโนมัติที่ทำงานเองต้องการพอดี

| | มีรา ผู้ช่วย AI (ในแอป) | MCP (ใน Claude หรือ ChatGPT) | API |
| --- | --- | --- | --- |
| ใครเป็นผู้ใช้ | คุณ ใน prepza | คุณ ในแชต AI ของคุณ | โค้ดของแพลตฟอร์มคุณ |
| ขออย่างไร | ด้วยคำพูดของคุณเอง | ด้วยคำพูดของคุณเอง | คำขอตายตัวที่นักพัฒนาเขียน |
| ใครอนุมัติการเปลี่ยนแปลง | คุณ บนการ์ด | คุณ ในแอป AI ของคุณ | โค้ดของคุณ ตามที่เขียนไว้ |
| เหมาะกับ | คำถามและงานที่ทำได้เร็ว | ใช้ prepza ร่วมกับเครื่องมือและไฟล์อื่นของคุณ | ระบบอัตโนมัติที่ทำงานได้โดยไม่ต้องมีใครเฝ้า |
| ลงชื่อเข้าใช้ในนาม | คุณ | คุณ | คีย์ของบริษัท |

ใช้มีราหรือ MCP เมื่อมีคนร่วมอยู่ในกระบวนการ ใช้ API เมื่อระบบของคุณเองต้องเชิญผู้สมัครและเก็บผลลัพธ์ได้เอง เช่น จากเว็บไซต์รับสมัครงานหรือเครื่องมือ HR ภายในองค์กร

## มีประโยชน์อะไรในการสรรหา

การสรรหามีขั้นตอนเล็ก ๆ ที่ต้องทำซ้ำ ๆ กระจายอยู่ในหลายเครื่องมือ และนั่นคือสิ่งที่เอเจนต์ทำได้ดี:

- **คำถามเกี่ยวกับความคืบหน้าการสรรหา** "สัปดาห์นี้มีผู้สมัครคนไหนผ่าน Senior Backend บ้าง" "ใครยังไม่ได้เริ่มการสัมภาษณ์" "ผลการประเมินเฉลี่ยของตำแหน่งนักวิเคราะห์ข้อมูลเป็นเท่าไร"
- **การตั้งค่า** "สร้างการสัมภาษณ์จากประกาศงานนี้" "ตั้งเกณฑ์ผ่านเป็น 70%" "ให้เวลาเพิ่ม 50% กับผู้สมัครคนนี้"
- **งานทีละมาก ๆ** "เชิญ 12 คนนี้เข้าการสัมภาษณ์ตำแหน่ง Frontend" โดยวางรายชื่อจากอีเมลหรือสเปรดชีตได้เลย
- **การรวมข้อมูลจากหลายแหล่ง** ใน Claude หรือ ChatGPT คุณใช้ prepza ร่วมกับเครื่องมือและไฟล์อื่นที่เชื่อมต่อไว้ได้ เช่น เทียบประกาศงานในเอกสารของคุณกับหัวข้อของการสัมภาษณ์ หรือร่างข้อความถึงผู้สมัครที่ผ่านเข้ารอบ

สิ่งที่เอเจนต์ไม่ควรทำคือตัดสินใจจ้าง ผลการประเมินช่วยสนับสนุนการตัดสินใจของคน แต่ไม่ได้มาแทนที่ ให้เอเจนต์ช่วยจัดลำดับ สรุป และเตรียมข้อมูล แล้วให้คนเป็นผู้ตัดสินใจ ดู [การใช้ AI ในการจ้างงานถูกกฎหมายใน EU หรือไม่?](/guides/is-ai-hiring-legal-in-the-eu) ว่าทำไมเรื่องนี้จึงสำคัญในทางกฎหมายด้วย

## สิ่งที่ต้องระวัง

การเชื่อมต่อ AI กับข้อมูลการสรรหาของคุณควรทำอย่างระมัดระวัง เหมือนกับการให้สิทธิ์เข้าถึงแก่เพื่อนร่วมงาน

| ความเสี่ยง | สิ่งที่ช่วยได้ |
| --- | --- |
| เอเจนต์ทำสิ่งที่คุณไม่ได้ตั้งใจ | การเปลี่ยนแปลงต้องได้รับอนุมัติจากคุณก่อน และเอเจนต์ทำเฉพาะสิ่งที่คุณขอ |
| เห็นข้อมูลมากเกินกว่าที่ควร | ทำงานในนามของคุณ เห็นเฉพาะสิ่งที่คุณเห็น ไม่มากไปกว่านั้น |
| คำสั่งที่ซ่อนอยู่ในข้อมูล | ชื่อ คำตอบ และเอกสารของผู้สมัครเป็นข้อมูล ไม่ใช่คำสั่งที่ต้องทำตาม |
| ข้อมูลลับหลุดเข้าไปในแชต | คีย์ API และรหัสผ่านไม่ผ่านแชตเด็ดขาด |
| ความผิดพลาดที่ย้อนกลับไม่ได้ | การลบบัญชีหรือบริษัททำได้เฉพาะในแอป และต้องยืนยันแยกต่างหาก |
| ข้อมูลออกไปนอกเครื่องมือของคุณ | ข้อมูลไปถึงแอป AI ที่คุณเชื่อมต่อ ภายใต้เงื่อนไขของแอปนั้น เชื่อมต่อเฉพาะแอปที่บริษัทอนุญาต |
| การใช้งานที่เกินควบคุม | มีขีดจำกัดจำนวนการทำงานต่อชั่วโมง |

ก่อนเชื่อมต่อแอป AI ใด ๆ กับข้อมูลงาน ให้ตรวจนโยบายของบริษัทเกี่ยวกับเครื่องมือ AI และแจ้งผู้สมัครในประกาศความเป็นส่วนตัวว่ามีบริการใดบ้างที่ประมวลผลข้อมูลของพวกเขา

## สามวิธีใช้ prepza นอกเหนือจากหน้าเว็บ

### 1. มีรา ผู้ช่วย AI ในตัว

เลือก **ถามมีรา** ที่ส่วนหัวของหน้าใดก็ได้ มีรา ผู้ช่วย AI ของ prepza รู้จักบริษัท การสัมภาษณ์ ผู้สมัคร เครดิต และการเชื่อมต่อระบบของคุณ รวมถึงวิธีการทำงานของ prepza มีราตอบเป็นภาษาของคุณ และคุณจะพิมพ์หรือพูดก็ได้

- **ตอบจากข้อมูลของคุณ** โดยเห็นเหมือนที่คุณเห็น ผู้ดูแลเห็นสิ่งที่ผู้ดูแลเห็น ผู้ดูเห็นสิ่งที่ผู้ดูเห็น
- **รู้ว่าคุณอยู่หน้าไหน** ถาม "ฉันทำอะไรได้บ้างในหน้านี้" เพื่อดูคู่มือของหน้านั้น หรือถาม "ใครดีที่สุดในนี้" ในหน้าผู้สมัครของการสัมภาษณ์ แล้วเอเจนต์จะตอบเรื่องการสัมภาษณ์นั้นโดยไม่ต้องถามว่าหมายถึงการสัมภาษณ์ไหน
- **เอเจนต์เตรียมการเปลี่ยนแปลง คุณเป็นผู้ยืนยัน** เมื่อขอให้เชิญผู้สมัคร เอเจนต์จะแสดงการ์ดที่บอกชัดเจนว่าจะเกิดอะไรขึ้น เช่น "เชิญผู้สมัคร 12 คนเข้าสัมภาษณ์ Backend developer" จะไม่มีอะไรทำงานจนกว่าคุณจะเลือก "ยืนยัน"
- **แสดงแหล่งที่มา** ใต้คำตอบ คุณจะเห็นผู้สมัครหรือการสัมภาษณ์ที่เอเจนต์ใช้ พร้อมลิงก์ไปยังหน้าที่ข้อมูลนั้นมา
- **ไม่ออกนอกเรื่อง** เอเจนต์ตอบเรื่อง prepza และการสรรหาด้วย prepza และปฏิเสธเรื่องอื่น

### 2. ใช้ prepza ใน Claude หรือ ChatGPT ผ่าน MCP

ถ้าทีมของคุณทำงานใน Claude หรือ ChatGPT อยู่แล้ว คุณนำ prepza ไปใช้ที่นั่นได้ เซิร์ฟเวอร์ MCP ของ prepza มีเครื่องมือชุดเดียวกับมีรา ผู้ช่วยในตัว

**วิธีเชื่อมต่อ:**

1. ใน prepza เปิดแท็บ **การเชื่อมต่อระบบ** ของบริษัท แล้วเลือก **แอป AI** คัดลอกที่อยู่เซิร์ฟเวอร์: `https://prepza.ai/mcp`
2. **ใน Claude:** เปิดการตั้งค่า ไปที่ตัวเชื่อมต่อ แล้วเพิ่มตัวเชื่อมต่อแบบกำหนดเองด้วยที่อยู่นั้น **ใน Claude Code:** รัน `claude mcp add --transport http prepza https://prepza.ai/mcp` **ใน ChatGPT:** เพิ่มเป็นตัวเชื่อมต่อแบบกำหนดเองในการตั้งค่าแอปและตัวเชื่อมต่อ
3. แอป AI ของคุณจะเปิดหน้าลงชื่อเข้าใช้ของ prepza ลงชื่อเข้าใช้ ตรวจว่าแอปใดกำลังขอสิทธิ์ แล้วเลือก **อนุญาต** หากต้องการให้อ่านได้อย่างเดียว ให้ปิด **อนุญาตให้เปลี่ยนแปลง** ก่อน

จากนั้นถามในแชตได้เหมือนถามเพื่อนร่วมงาน: "ใน prepza ผู้สมัคร 3 อันดับแรกของ Product designer คือใคร" แอป AI ส่วนใหญ่จะถามคุณก่อนเปลี่ยนแปลง และเตือนก่อนทำสิ่งที่ย้อนกลับไม่ได้ เพราะ prepza บอกแอปว่าการดำเนินการใดเปลี่ยนแปลงหรือลบข้อมูล

**สิ่งที่เหมือนกับในแอป:**

- **สิทธิ์ของคุณ** ทำงานในนามของคุณ ในทุกบริษัทที่คุณอยู่ ตามบทบาทของคุณในแต่ละบริษัท
- **เครดิตและขีดจำกัด** การเชิญผู้สมัครใช้เครดิตเท่ากับในแอป และใช้ขีดจำกัดอีเมลเดียวกัน
- **บันทึก** ทุกอย่างที่แอป AI ทำแทนคุณจะแสดงในบันทึกการดำเนินการของบริษัทว่าทำผ่านแอป AI ตั้งแต่การอนุมัติหัวข้อและการดูผลลัพธ์ ไปจนถึงการให้เวลาเพิ่มหรือการเพิกถอนผู้สมัคร เจ้าของบริษัทอ่านได้ในแท็บ **บันทึกการดำเนินการ** ของบริษัท
- **บริษัทเป็นผู้ตัดสินใจ** เจ้าของและผู้ดูแลสามารถหยุดไม่ให้แอป AI ใช้ข้อมูลของบริษัทได้ด้วย **อนุญาตแอป AI ในบริษัทนี้** ในหน้าแอป AI ของบริษัท
- **สิ่งที่ทำไม่ได้** มองไม่เห็นรหัสผ่านหรือคีย์ API ของคุณ และลบบัญชีหรือบริษัทไม่ได้ เรื่องเหล่านี้ทำได้เฉพาะในแอป

**วิธียกเลิกการเชื่อมต่อ** ลบตัวเชื่อมต่อในแอป AI ของคุณ หรือเลือก **ยกเลิกการเชื่อมต่อ** ข้างแอปนั้นใต้ **แอป AI** ในแท็บการเชื่อมต่อระบบ แอปจะหยุดทำงานทันที

**แอปอื่นและเอเจนต์ของคุณเอง** [แท็บ MCP](/api-docs?tab=mcp) ในเอกสารสำหรับนักพัฒนามีขั้นตอนสำหรับ Gemini CLI, Cursor, VS Code และ Le Chat รวมถึงตัวอย่างเอเจนต์ที่สมบูรณ์ใน Python และ TypeScript เอเจนต์ที่ทำงานบนเซิร์ฟเวอร์ ซึ่งไม่มีใครคอยอนุมัติการลงชื่อเข้าใช้ จะใช้คีย์ API ของบริษัทที่มีสิทธิ์ **ใช้กับเอเจนต์ AI (MCP)** คีย์นี้ใช้ได้เฉพาะในบริษัทนั้น และใช้ได้เฉพาะเครื่องมือที่สิทธิ์อื่นของคีย์อนุญาต

### 3. แพลตฟอร์มของคุณเอง ผ่าน API

สำหรับระบบอัตโนมัติที่ไม่ใช้ AI prepza มี API ซึ่งอธิบายไว้ใน [เอกสารสำหรับนักพัฒนา](/api-docs)

1. เจ้าของหรือผู้ดูแลเปิดแท็บ **การเชื่อมต่อระบบ** ของบริษัท ไปที่ **API** แล้วเลือก **คีย์ใหม่** ตั้งชื่อคีย์ตามแพลตฟอร์มที่จะใช้ เลือกวันหมดอายุ และเลือกเฉพาะสิ่งที่คีย์ต้องใช้ เช่น คีย์ของแดชบอร์ดอ่านได้อย่างเดียว ส่วนคีย์ของเว็บไซต์รับสมัครงานเชิญผู้สมัครได้ด้วย คุณเพิ่มหรือถอนสิทธิ์ภายหลังได้ คีย์จะแสดงเพียงครั้งเดียว ให้เก็บไว้ในที่ปลอดภัย
2. แพลตฟอร์มของคุณส่งคำขอด้วยคีย์นั้น เช่น ดูรายการการสัมภาษณ์ของบริษัท ดูรายชื่อหรือข้อมูลผู้สมัครพร้อมผลการประเมิน ผ่านหรือไม่ และสัญญาณเตือนด้านความซื่อตรง และเชิญผู้สมัคร
3. เพิ่ม **เว็บฮุก** ซึ่งเป็นที่อยู่บนแพลตฟอร์มของคุณที่ prepza จะเรียกพร้อมลายเซ็นเมื่อผู้สมัครเริ่มทำ ทำเสร็จ คำเชิญส่งไม่ถึง คำเชิญหมดอายุ หรือผู้สมัครถูกลบออก และเมื่อการสัมภาษณ์พร้อมใช้งาน คุณจึงไม่ต้องคอยถามซ้ำ ๆ หน้า API ส่งเหตุการณ์ทดสอบไปยังเว็บฮุกได้ และแสดงบันทึกการส่งของเว็บฮุกนั้น

ผู้สมัครแต่ละคนมาพร้อมลิงก์ไปยังผลลัพธ์ฉบับเต็มใน prepza และลิงก์คำเชิญของตัวเองจนกว่าจะทำเสร็จ แพลตฟอร์มของคุณจึงส่งลิงก์นั้นในข้อความของตัวเองได้ถ้าคุณต้องการ หากแพลตฟอร์มของคุณรู้อยู่แล้วว่าผู้สมัครเป็นใคร ให้เชิญโดยไม่ต้องลงชื่อเข้าใช้ prepza จะไม่ส่งอีเมลใด ๆ และผู้สมัครทำการสัมภาษณ์จากลิงก์ได้โดยไม่ต้องลงชื่อเข้าใช้ prepza จึงควรส่งลิงก์ให้ผู้สมัครคนนั้นเท่านั้น คำเชิญยังพาผู้สมัครกลับไปยังเว็บไซต์ของคุณได้ด้วยปุ่มบนหน้าที่แสดงเมื่อทำเสร็จ และตั้งธีมสว่างหรือมืดในสีของบริษัทคุณได้ ด้วย SDK ของ prepza หน้าเว็บของคุณเองก็แสดงการสัมภาษณ์ได้โดยตรง การพาผู้สมัครกลับไปยังเว็บไซต์ของคุณและการแสดงการสัมภาษณ์บนเว็บไซต์ของคุณต้องใช้บริษัทที่ยืนยันแล้ว และใช้ได้เฉพาะบนโดเมนเว็บไซต์ของบริษัทนั้นเท่านั้น

กฎเดียวกับที่อื่นยังใช้อยู่ ผลการประเมินช่วยสนับสนุนการตัดสินใจของคน อย่าปฏิเสธผู้สมัครโดยอัตโนมัติจากผลการประเมินอย่างเดียว

## ควรใช้อะไรเมื่อไร

เริ่มจากว่าใครเป็นคนทำงาน และทำบ่อยแค่ไหน

| สถานการณ์ของคุณ | ใช้ |
| --- | --- |
| คุณอยู่ใน prepza และอยากได้คำตอบเร็ว ๆ เช่น ใครผ่าน ใครยังไม่เริ่ม เหลือเครดิตเท่าไร | มีรา ผู้ช่วยในตัว |
| คุณอยากตั้งค่าด้วยคำไม่กี่คำ เช่น สร้างการสัมภาษณ์จากประกาศงาน ตั้งเกณฑ์ผ่าน ให้เวลาเพิ่ม | มีรา ผู้ช่วยในตัว |
| คุณทำงานใน Claude หรือ ChatGPT ทั้งวันอยู่แล้ว และอยากใช้ prepza ที่นั่นด้วย | MCP |
| งานต้องใช้ prepza ร่วมกับอย่างอื่น เช่น เอกสารของคุณ ร่างอีเมล หรือเครื่องมืออื่นที่เชื่อมต่อไว้ | MCP |
| รีครูตเตอร์ที่อยู่นอกสถานที่อยากดูความคืบหน้าการสรรหาจากแอป AI บนโทรศัพท์ | MCP |
| เว็บไซต์รับสมัครงานหรือระบบ HR ของคุณควรเชิญผู้สมัครได้เอง โดยไม่ต้องมีใครคลิก | API |
| ผลลัพธ์ควรเข้าไปอยู่ในฐานข้อมูลหรือแดชบอร์ดของคุณเองทันทีที่ผู้สมัครทำเสร็จ | API พร้อมเว็บฮุก |
| ATS ของคุณเป็นระบบที่ prepza เชื่อมต่อได้ (Workable, Greenhouse, Teamtailor, Recruitee, Breezy HR) | ไม่ต้องใช้ทั้งสามอย่าง: เชื่อมต่อ ATS ในแท็บการเชื่อมต่อระบบ ดู [วิธีเชื่อมต่อแบบทดสอบทักษะกับ ATS](/guides/ats-integration-skills-tests) |

หลักง่าย ๆ:

- **คนเป็นผู้ถาม และตรวจทุกการเปลี่ยนแปลง:** ใช้มีราใน prepza หรือ MCP ถ้าคนคนนั้นทำงานอยู่ใน Claude หรือ ChatGPT เป็นหลัก
- **ซอฟต์แวร์ทำงานเอง ด้วยวิธีเดิมทุกครั้ง:** ใช้ API
- **เพิ่งเริ่มต้น:** ลองใช้มีรา ผู้ช่วยในตัวก่อน ไม่ต้องตั้งค่าอะไร และสิ่งที่คุณเรียนรู้นำไปใช้กับ MCP ได้ต่อ

ทั้งหมดนี้ยังใช้ร่วมกันได้ด้วย ทีมหนึ่งอาจส่งคำเชิญจากระบบ HR ผ่าน API ขณะที่รีครูตเตอร์ถามมีราหรือแชต AI ของตัวเองเกี่ยวกับผลลัพธ์

## วิธีได้ผลลัพธ์ที่ดี

- **ระบุชื่อให้ชัด** "การสัมภาษณ์ Senior Backend" ได้ผลดีกว่า "การสัมภาษณ์นั้น"
- **ขอทีละขั้นตอน** เมื่อเป็นเรื่องสำคัญ ตรวจผลลัพธ์ก่อน แล้วค่อยขอขั้นต่อไป
- **อ่านรายการที่ต้องอนุมัติก่อนอนุญาต** รายการนั้นแสดงชัดเจนว่าจะมีอะไรทำงานบ้าง
- **ถามว่าตัวเลขมาจากไหน** เอเจนต์ที่ดีชี้ได้ว่าผู้สมัครหรือหน้าใดอยู่เบื้องหลังตัวเลขนั้น
- **ให้คนเป็นผู้ตัดสินใจ** ใช้เอเจนต์ช่วยค้นหา จัดลำดับ และเตรียมข้อมูล แล้วตัดสินใจด้วยตัวเอง
